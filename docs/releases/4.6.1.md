# ClaudeDock 4.6.1 发布说明

4.6.1 是问题审计与方案沟通版本，不修改 ClaudeDock 的 UI、IPC、PTY、模型路由或会话运行行为。

## 变化

- 新增根目录 `当前版本需改进的bug.md`，记录 11 组用户反馈的代码审计结论。
- 区分已确认缺陷、现有架构边界、能力缺口和需要实测的问题。
- 给出终端缩放/主题、异常恢复、历史单一归属、跨主题布局、图片附件、任务摘要、ConPTY 故障、
  更新进度、GPT Fast 和按模型能力联动的候选方案与推荐顺序。
- 明确任何 UI 或架构实现都要在用户选择方案后另行开发和验证。

## 发布边界

本地 `npm run dist` 产物只用于开发验证。未完成受信任 Authenticode 签名、release manifest 签名、
安装/卸载烟测与 GitHub/国内镜像双渠道门禁前，不得描述为 4.6.1 正式稳定版。2026-08-07 的
`npm audit` 还报告 `js-yaml` 高危和 `mermaid` 中危公告；依赖修复、回归和重新审计完成前同样阻止
稳定发布。
