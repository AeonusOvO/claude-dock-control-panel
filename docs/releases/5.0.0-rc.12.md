# ClaudeDock 5.0.0-rc.12

发布日期：2026-08-16

## 融合范围

- 修复实验性“ChatGPT 订阅（ClaudeDock 托管）”在尚未打开项目时点击“一键安装并登录”无响应的问题。
  Claude Code 检测/补齐、网关安装、OpenAI 授权、网关启动和模型发现可以先完成全局准备；打开项目后
  再执行项目级模型实测与保存。Renderer 本地点击租约与主进程进度分开追踪，完整全局事务由主进程
  single-flight 协调；跨项目、重复点击、Renderer 重载或失败重试都不会重复安装或留下失效禁用态。
- 修复 PowerShell/ConPTY 与结构化原生对话不能可靠往返的问题。切换保持当前标签页和对话 UUID；
  无运行任务时直接切换，有回复、排队/等待任务或 Web 进程时显示“中断并切换”确认，取消保持原界面，
  确认后才释放 owner。终端销毁前和异步准备后都会重新检查运行状态，避免竞态中断任务。
- 融合原生会话提交、恢复和附件可靠性更新：单一发送/停止按钮按输入意图切换，交互请求按队列展示，
  提交确认按会话与提交 ID 隔离；草稿继续使用加密恢复，存储更新采用原子写入和短暂锁重试，致命流错误
  会关闭失效队列并释放会话所有权。
- 融合 Claude 上下文资源设置。用户可选择自动、20 万、100 万或自定义窗口；请求值与当前会话的
  上游真实读数分开显示，模型 ID 在 CLI/Agent SDK 边界规范化，端点拒绝时提供安全回退提示。
- 融合下载、网络与进程生命周期守栏，包括恢复日志与完整性校验、代理作用域隔离、官方端点预检、
  网关/Router 操作协调以及退出和所有权清理，避免旧配置、迟到回调或孤儿进程污染新会话。
- 融合输入坞、底栏菜单、响应式布局与四主题设计系统。原有大体积样式入口拆为 14 个按层级和视图组织的
  CSS 模块，并补充键盘焦点、动效、选择器、布局与主题计算样式回归覆盖。

## 文档治理

- 恢复根目录 `AGENTS.md`，并把“完整门禁、每次构建安装包、报告路径/版本/大小/SHA-256/签名状态”
  固化为当前仓库维护规则。
- 恢复旧版计划、路线图、缺陷清单和分阶段修复提示词的完整原文，移入 `docs/archive/`，并在每份文件
  开头明确标记“历史材料 / 非当前规格”。这些归档文件不得覆盖当前 README、设计、技术说明、代码和测试。
