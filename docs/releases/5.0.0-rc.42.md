# ClaudeDock 5.0.0-rc.42

发布日期：2026-08-28

## 变更

- 修复 ChatGPT 官方订阅额度在启动或模型恢复期间被托管网关生命周期取消后，错误等待下一次一分钟轮询的问题。
- 托管网关生命周期开始时使进行中的额度读取失效；全部生命周期结束并恢复可读后，针对当前账户、接入代次和模型合并补发一次查询。
- 选择 ChatGPT 模型时若网关已经处于生命周期中，等待网关稳定后再读取，不在不可读阶段发起无效请求；普通生命周期不会因此产生额外请求突发。
- 区分普通网关更新与账户/授权切换的旧数据提示；账户切换、模型切换、授权变化和迟到结果继续保持隔离。
- 补查只复用现有托管授权和应用网络 Session，不启动独立 Codex 登录，不重新授权、不刷新凭据、不运行网络预检，也不把账户或额度协调元数据发送到 renderer。

## 验证门禁

- 额度服务、托管网关、额度读取器和生产账户接线覆盖生命周期事件顺序、取消、并发合并、账户与模型 fencing、不可读阶段选择、普通轮询和释放清理。
- Electron 额度冒烟使用生产网络 transport、合成托管授权和本地回环服务，验证授权文件不变、无 Cookie、无独立 Codex 登录、响应限制、超时取消和主线程流畅度；不访问真实账户。
- 最终候选必须在 exact clean commit 上执行完整质量门禁和 Windows/Electron 打包门禁，再生成同一构建 cohort 的 NSIS 安装包、blockmap 和 rc.yml。
- COS 通道发布、匿名下载校验和真实客户端安装更新验收分开记录；未执行的生产安装不标记为通过。
