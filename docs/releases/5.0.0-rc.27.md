# ClaudeDock 5.0.0-rc.27

发布日期：2026-08-26

## 变更

- 接入页改为应用级“下个对话接入”：无需先打开项目或终端即可选择、真实测试并保存平台和模型；每次进入
  都先显示“选择模型”，项目/会话状态更新不再清空页面或强制跳转。
- 新 Claude 终端与全新原生对话会在创建瞬间复制独立接入 profile。并行点击、切换前台或随后更换下个模型
  都不会取消、串改已接受的后台启动。
- ChatGPT 一键流程从第 6 步继续完成模型发现、真实测试和全局保存；模型下拉在无项目时可用，并优先推荐
  GPT-5 系列而不是列表首项 GPT-4o。
- “自动连接最近一次选择的平台和模型”继续默认开启，启动时即使同时自动恢复对话也会先验证并恢复完整
  接入；关闭后明确回到“尚未选择接入”。
- 全局保存和模型切换失败会恢复原 profile、下拉值、摘要与按钮状态，并显示错误，不再保留无限 loading
  或伪成功界面。

## 验证门禁

- 回归测试必须覆盖无项目 ChatGPT 全流程、接入页重入、延迟读取 fencing、全局配置 FIFO 与回滚，以及
  终端/原生会话的不可变接入快照。
- 完整门禁必须通过 lint、dependency lint、format、三个 tsconfig、全部 Vitest、构建、布局、控件主题、
  四主题视觉、加速 24 小时 soak 与 `npm run dist`。
- 安装包、blockmap 与 `rc.yml` 必须来自同一次最终构建；只有 COS 通道推进并从真实旧版本完成检查、下载、
  安装、自动重启和版本确认后，才能标记为用户可更新。

## GitHub Release 摘要 / Summary

**中文**

本候选版把平台和模型变为真正独立于项目的“下个对话接入”，修复空白/错误跳转、ChatGPT 第 6 步后未接入、
模型下拉禁用与 GPT-4o 误选，并确保并行后台会话固定使用创建时的接入配置。

**English**

This release makes platform and model selection a project-independent next-conversation setting, completes the
projectless ChatGPT flow through real verification and persistence, restores honest UI rollback, and gives every
concurrent terminal or native conversation an immutable connection snapshot captured at creation time.
