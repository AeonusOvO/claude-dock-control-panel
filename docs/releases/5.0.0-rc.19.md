# ClaudeDock 5.0.0-rc.19

发布日期：2026-08-25

## 变更

### 接入页布局与操作胶囊

- 接入页的模型来源卡片增加自适应高度、内边距和间距；步骤 viewport 保留主题阴影、键盘焦点环和
  前进/返回动画的完整绘制范围，不再从边缘裁切。
- “上一步 / 当前状态 / 下一步”重做为主题化长胶囊，使用实时 backdrop 高斯模糊、语义表面、边框、
  阴影、字体和圆角 token；按钮贴合胶囊两端且保持统一字号与高度。
- 宽窗口保留 sticky 操作胶囊；紧凑窗口让胶囊回到内容流，避免覆盖第二排模型卡片。四主题均覆盖
  820px 与 1180px 截图，布局门禁同时检查胶囊滚动到可见位置后的完整边界。

### 更新安装

- “下载并更新”成为单一显式事务：下载与 SHA-512 校验完成后自动静默安装、重启，不再要求第二次
  点击“重启并安装”或确认。
- 后台刷新继续严格 check-only；并发下载与安装请求合并，批量更新固定最后处理 ClaudeDock，避免应用
  退出后遗留其他更新。
- 安装前先锁定新会话并清理 ClaudeDock 自有进程；同步清理失败、安装器启动失败和 updater 异步错误
  都会恢复退出闩并进入可重试状态，进程观察器不会提前停止。

### 首次引导

- 四个步骤后退按钮统一从“返回”改为“上一步”，其他“返回设置 / 返回终端”等不同语义文案保持不变。
- 退场步骤不再继承会撑高 viewport 的最小高度；前进与后退动画中不会闪现右侧滚动条，真实长内容仍可
  正常滚动。

## 验证契约

- 完整门禁必须通过 lint、dependency lint、format、三个 tsconfig、全部 Vitest、构建、布局、主题、视觉、
  加速 24 小时 soak 与 `npm run dist`。
- 最终安装包、blockmap 与 `rc.yml` 必须来自同一 exact commit 和 build cohort；COS 先发布不可变资产，
  最后推进 no-cache 的 `rc.yml`。
- 必须从实际安装的 rc.18 使用右上角“检查更新”发现 rc.19；检查本身不得下载，点击一次“下载并更新”
  后应完成下载、校验、静默安装、自动重启和版本确认。

测试数量、产物大小、SHA-256、cohort 与 Authenticode 状态只取最终候选日志和
`outputs/release-manifest.json`，不在构建前写死。

## GitHub Release 摘要 / Summary

**中文**

本候选版重做接入页的响应式卡片与主题玻璃操作胶囊，修复边缘裁切和紧凑窗口遮挡；应用更新改为一次
“下载并更新”后自动静默安装与重启，并修复首次引导切换时的瞬时滚动条。

**English**

This release candidate adds responsive access cards and a theme-aware glass action capsule without clipping or
compact-window occlusion, advances an explicit download-and-update action through silent install and restart, and
removes the transient onboarding scrollbar during step transitions.
