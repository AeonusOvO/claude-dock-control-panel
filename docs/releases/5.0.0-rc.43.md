# ClaudeDock 5.0.0-rc.43

发布日期：2026-08-29

## 变更

- 修复 ChatGPT 官方订阅账户摘要在运行时状态刷新期间反复回到“正在读取账户…”的问题；同一接入复用安全的最近一次账户身份，并合并进行中的读取请求。
- 为账户读取增加连接身份、代次和生命周期隔离；配置切换、登出、授权变化、托管网关忙碌或暂时失败时，迟到结果不会覆盖当前接入，且不会无限重试或重新注入旧账户。
- 保持 ChatGPT 托管账户与 Anthropic 官方账户、Codex 及其他接入的读取边界；renderer 只接收经过安全投影的账户身份，不接收 token、管理密钥或原始凭据。
- 修复托管网关生命周期与额度刷新之间的同步竞态，确保账户或授权变化后的额度读取不会因网关忙碌或同步回调而丢失。
- 为新建会话和历史会话恢复显示实际阶段，包括读取配置、准备终端、准备网络访问、等待网络确认、读取或切换历史模型、恢复对话、重启及启动 Claude Code；关闭后台网络预检后不再把必要的启动准备误报为预检。
- 将阶段提示同步到项目列表、工作区预览、终端遮罩、启动控件和原生输入区；动态提示使用可访问的状态语义，进度刷新后保留键盘焦点，并防止嵌套遮罩的旧 owner 覆盖新 owner 的文案。
- 为账户摘要和启动进度补充生命周期清理、取消、并发、stale-result、焦点和托管网关回归覆盖。

## 验证门禁

- 账户读取、托管网关额度、启动阶段、历史恢复、终端遮罩、项目列表和原生输入区均通过对应的行为回归；覆盖重复渲染、并发读取、失败重试、生命周期失效、取消、排队和迟到结果隔离。
- 最终候选必须在 exact clean commit 上执行完整质量门禁和 Windows/Electron 打包门禁，再生成同一构建 cohort 的 NSIS 安装包、blockmap 和 rc.yml。
- COS 通道发布、匿名下载校验和真实客户端安装更新验收分开记录；未执行的生产安装不标记为通过。
