# ClaudeDock 5.0.0-rc.1

发布日期：2026-08-07

这是 5.0 原生对话架构的完整候选版，不是稳定发布。

## 主要变化

- Claude 项目默认使用 Agent SDK 驱动的原生 DOM 对话，支持结构化 Markdown、工具、权限、提问、
  计划、MCP、图片、后台任务和中断；高级 PowerShell/ConPTY 终端保留为明确入口。
- 新增会话单 owner、精确 UUID 恢复、加密恢复日志和“不确定提交绝不自动重发”策略；进行中 UUID
  不再与历史条目重复显示。
- 新增版本化模型能力状态；Ultra Code 明确区分工作流预设和实际 X-High，Fast 不再承诺固定倍率。
- 新增 Codex 风格的当前对话摘要、主题化终端诊断和“任务与下载”进度模型。
- 原生 Claude 输入支持安全图片粘贴、拖放和选择；补齐 Windows 剪贴板兼容与附件孤儿清理。
- 原生 DOM 连续响应窗口与缩放，终端 resize 采用 RAF 合并和双层同尺寸去重；历史尾槽、四主题和
  200% 缩放均纳入视觉矩阵。
- 原生交互坞按队列一次只显示一个权限、提问、计划或 MCP 请求；文字按钮与标题栏图标分别复用统一
  组件基类，移除标题区重复的模型、Ultra 与实际档位说明。

## 安全与兼容边界

- 发行包不包含第二份 Claude Code；Agent SDK 只调用用户已安装的 `claude.exe`，打包后自动扫描验证。
- Codex 仍使用原生 TUI；App Server 结构化迁移留待后续版本。
- 隔离测试 profile 不读取真实会话、凭据或项目，不启动真实 PTY、托盘、更新器或外部配置写入。
- 本 RC 未完成可信 Authenticode、双渠道镜像和稳定更新/回滚验收，不得描述为正式 5.0 稳定版。

## 本地验证

- 完整 `verify` 通过：116 个测试文件、863 项测试，以及 lint、format、typecheck、layout、
  control-theme、build 和 ConPTY smoke。
- 静态视觉矩阵与真实隔离 Electron 交互截图通过；原生矩阵 56 张、真实窗口 14 张。
- 生产依赖审计无已知漏洞；安装包扫描无重复 `claude.exe`，也未发现凭据或本机用户路径残留。
- 生成 `ClaudeDock-Setup-5.0.0-rc.1-x64.exe`、blockmap、`latest.yml` 和 `win-unpacked/`。
- 当前本地候选包的 Authenticode 状态为 `NotSigned`；它可用于内部 RC 验证，不能作为正式稳定发布。
