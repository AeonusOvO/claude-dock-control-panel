# ClaudeDock 5.0.0-rc.17

发布日期：2026-08-24

## 变更

### 工作区与导航

- 顶层导航收敛为“工作区 / 独立对话 / 接入 / 扩展”，设置保留在活动栏底部；接入与扩展使用完整内容画布，
  插件和 MCP 服务在扩展页内作为同级分段。
- 项目运行时选择器改为按需展开，工作区默认聚焦项目与终端；再次点击当前完整画布入口会沿原路径返回工作区。
- 空工作区同时提供添加项目和打开入门向导，降低首次使用时对终端、路由和模型标识的理解要求。

### 启动引导

- 新增“选择路径 → 自动准备 → 打开项目 → 准备完成”四步引导，覆盖 Claude Code、ChatGPT / Codex
  与 API 服务商三种接入方向。
- 引导进度由 main 进程版本化持久化，支持跳过、续接、重置和旧用户迁移；持久化数据不包含密钥、令牌或
  项目正文。
- 环境检测明确区分已就绪、待安装、项目后检测与自动处理，不把未知状态展示为成功。

### 主题、排版与动效

- 四套主题继续使用各自适配的组件与字体系统，统一按钮字号、文字层级、焦点状态和窄窗口布局。
- 引导、完整画布、分段切换和返回操作使用来源可追踪的空间动效；进入与退出沿同一原点，前进与返回方向对称。
- 动效使用非线性缓动并尊重系统减少动态效果设置。

### 质量与发布

- 补齐启动引导 store、IPC、preload 和 renderer 行为测试，以及真实 Electron 布局、主题和视觉冒烟覆盖。
- 正式更新交付必须递增版本并通过软件右上角“检查更新”完成发现、下载与安装；只提交代码或上传单个安装包
  不再视为发布完成。

## 验证契约

本版本必须在发行源码、测试与文档的 exact commit 上执行 [验证清单](../how-to/verify.md) 和完整
`npm run release`。最终候选必须额外确认：

- `outputs/release-manifest.json` 的问题列表为空，安装包、blockmap 与 `rc.yml` 属于同一次构建 cohort。
- 实际打包应用完成首次引导、跳过与续接、项目目录选择、工作区返回路径、四套主题和窄窗口自适应验收。
- COS 中先发布并公开验证不可变安装包与 blockmap，最后推进 `rc.yml`；公开长度、Range、缓存头与完整摘要
  均与本地 frozen manifest 一致。
- 从实际安装的 rc.16 使用右上角“检查更新”发现 rc.17，完成显式下载、重启安装和版本确认。

测试数量只取自 exact-commit 门禁日志；产物大小、SHA-256、SHA-512、cohort 和 Authenticode 状态只取自最终
候选的 `release-manifest.json`，不在最终候选运行前写死。

## GitHub Release 摘要 / Summary

**中文**

本候选版重构工作区导航并加入可续接的四步启动引导，为每套主题统一组件、字体与文字层级，同时为进入、返回、
步骤切换和完整画布交互补齐来源可追踪的非线性动效与窄窗口适配。

**English**

This release candidate refines workspace navigation and adds a resumable four-step onboarding flow, with
theme-specific components and typography, consistent hierarchy, origin-aware non-linear motion, and narrow-window
adaptation across the updated surfaces.
