# ClaudeDock 5.0.0-rc.6

发布日期：2026-08-08

## 修复

- 修复 Claude Agent SDK 流式事件没有稳定 UUID 时，每个 token 被拆成独立消息卡的问题。
- 最终 assistant 完整帧现在原位完成同一条流式回复，不再在末尾重复追加整段内容。
- renderer 将高频累计快照合并到浏览器下一绘制帧，并复用已有消息节点；流式阶段同步显示纯文本，
  完成后再渲染安全 Markdown，避免异步结果乱序、闪烁或破坏文本选择。
- 将仅开发链路的 `nanoid` 锁定版本从 3.3.16 更新到已修复公告的 3.3.18；生产与完整依赖审计均为
  0 项已知漏洞。

## 界面

- 用户提示词保留右侧强调色气泡。
- Claude 回复改为主题化 PowerShell 风格输出壳：宽输出列、等宽 `>_` 提示符、终端表面和流式光标，
  同时继续支持完成后的 Markdown、工具、思考和附件组件。

## 验证重点

- UUID 缺失的逐 token 事件与最终帧只能归并为一个完成消息。
- 四主题、窄窗口、项目栏宽度和减少动态效果下，用户/助手层次、滚动与输入区均保持稳定。
