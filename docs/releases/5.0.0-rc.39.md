# ClaudeDock 5.0.0-rc.39

发布日期：2026-08-28

## 变更

- 修复 ChatGPT 全局一键接入在授权前报 `spawn curl.exe ENOENT`：网络预检不再把不存在的逻辑配置
  profile 当成进程工作目录，改用当前用户真实的应用数据目录；授权身份、缓存和嵌套租约保持精确隔离。
- 本机探测组件无法启动时明确提示请求尚未发出；若接入在预检阶段被拦截，说明安装与 OpenAI 授权尚未
  开始，保留原有接入，不再把本机故障笼统呈现为账号授权失败或引导用户更改 DNS。
- 清除运行与发行代码对固定 Windows 系统盘符的兜底假设；PowerShell、curl 与签名检查从当前系统
  安装位置解析。签名检查无法定位系统组件时继续拒绝发布，不放宽原有信任门禁。
- 审计源码、运行脚本及构建配置中的机器路径；视觉夹具移除固定盘符，新增路径来源与可移植性文档。
  用户明确选择的项目/CLI 目录及运行时安全解析得到的绝对路径保持不变。

## 验证门禁

- 真实 Windows curl 回环回归必须在逻辑 profile 不存在、应用数据目录带中文和空格的情况下通过；测试
  不创建虚拟 profile，不访问真实账号或外部模型 API。
- 不同用户、非默认系统/安装盘符、资源重定位、SystemRoot/WINDIR 缺失或无效，以及本机启动失败分类
  都有行为回归；跨 profile/Provider/target 授权隔离继续成立。
- 最终候选执行 lint、format、三套 typecheck、全量 Vitest、依赖检查、真实 Electron 冒烟、Windows
  进程集成、24 小时加速 soak 和完整 `npm run release`，构建同批安装包、blockmap 与 rc.yml。
- 不使用 computer-use 操作生产软件，不自动重试用户账号授权；真实账号接入和生产客户端的安装重启
  不由上述无凭据回归替代。

## GitHub Release 摘要 / Summary

**中文**

修复 ChatGPT 接入前的本机目录错误，并移除固定系统盘符假设。网络预检与授权身份解耦，中文、空格和
自定义安装位置有回归覆盖；失败信息明确区分本机探测与账户授权。

**English**

Fixes projectless ChatGPT setup failing before authorization because a logical configuration scope was used as a
process working directory. Network probes now use the current runtime's real data directory without weakening
authorization isolation. System tools no longer assume a fixed Windows drive, and relocation and startup-error
regressions cover different users, Unicode and spaces.
