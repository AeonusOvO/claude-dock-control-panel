# ClaudeDock 4.1.0 发布说明

GitHub Release 的公开时间戳是正式发布日期；只有受信任 Windows 代码签名与双渠道发布门禁全部
通过时，该 Release 才会从 draft 转为稳定版。

维护者：AeonusOvO
公开联系电话：13585928550

## 主要变化

- GitHub Release 与国内 HTTPS 公网 IP 镜像使用同一组只构建、只签名一次的 Windows x64 产物。
- 新增 Ed25519 签名的 release manifest。GitHub 不可达时，客户端仍能用固定公钥独立验证镜像更新。
- 更新客户端拒绝 HTTP、未授权 IP、query、fragment、跨主机重定向、过大元数据、伪造 Range、
  版本回退、清单不一致和安装器摘要不一致。
- 下载前仅对已验证安装包读取小范围样本并选择更快来源；下载后再次验证完整长度和 SHA-512。
- 网络预检不再请求第三方公网地址、地区、ASN 或网络信誉服务，只检查本机路径与服务商官方端点。
- 发布流水线加入秘密扫描、完整依赖审计、强制 Authenticode/时间戳、安装卸载烟测、GitHub draft
  回读、服务器版本化 staging、原子切换和失败回滚。
- 国内兜底镜像使用 Let’s Encrypt short-lived 公网 IP 证书、Certbot 自动续期、Nginx reload hook、
  每小时证书监控和最小权限部署账号。
- 补齐 Apache-2.0 开源治理、贡献指南、行为准则、安全政策、Issue/PR 模板、代码签名政策及真实维护者
  联系方式。

## 安全与兼容性

- 最高已接受版本保存在本机，稳定更新不允许降级。
- 更新失败不会覆盖当前可运行版本；界面区分失败来源和校验阶段。
- 稳定安装器必须由公开受信任的 Authenticode 主体签署并带可信时间戳。未签名或自签名构建不属于
  4.1.0 正式 Release。
- 仅支持 Windows x64；旧版通用代理运行栈不会被重新启用。

## 发布验收

正式发布时必须在本文件或 GitHub Release 记录以下事实：

- 最终 tag、提交和 Release URL；
- Authenticode 签名主体、时间戳与 Windows 验证链结果；
- GitHub 与镜像安装器的大小和 SHA-512；
- GET、HEAD、Range/206、缓存头、manifest 签名、篡改/回退/渠道不一致和 GitHub 不可用测试；
- Certbot renewal dry-run、安装/卸载烟测及所有 CI job 结果；
- 尚待人工确认的法律或接入商事项。

详细隐私、合规和镜像说明见 `docs/PRIVACY.md`、`docs/LEGAL_COMPLIANCE.md` 与
`docs/UPDATE_MIRROR.md`。
