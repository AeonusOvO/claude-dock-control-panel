# ClaudeDock 5.0.0-rc.23

发布日期：2026-08-25

## 变更

### 启动时真正接回上次模型

- 软件启动后默认打开最后使用项目中最近的对话，并恢复该对话绑定的平台、账户/API、接口、详细模型与
  简单模型；不再只打开一个空项目终端，也不会用当前平台悄悄替代上次对话的模型。
- 自动恢复与手动选择“使用该对话原有模型”共用真实连接测试和可回滚配置事务。完整绑定无法恢复或测试
  失败时保留原接入并给出明确错误，不会启动错误模型的 Claude 会话。

### 两个独立启动开关

- “自动加载上次对话”和“自动加载模型”拆成两个默认开启、可独立保存的选项：可以同时恢复对话与模型，
  只恢复对话内容，或只在后台接回最近对话的模型而不打开对话。
- 旧版本的“启动时恢复上次工作区”选择会迁移到两个新开关，升级后保持原有开启或关闭意图；关闭开关
  不会删除已记住的项目、历史对话或模型绑定。

### 连接中的可见反馈与设置层级

- 自动连接期间在终端中央显示带旋转动效的“正在连接模型…”。composer、xterm stdin 与底层终端写入
  同时锁定；输入框从静态首帧起即为禁用态，模型识别也在遮罩出现后执行，只有模型事务与 CLI 启动
  完成后才恢复输入，避免用户把内容输进尚未就绪的 PowerShell。
- 通用设置重新整理为“启动与恢复 / 对话与模型 / 窗口与外观 / 关于”四组卡片；分组与连接遮罩都有
  主题化动效并服从 reduced-motion，标准和窄窗口都必须保持可滚动、无裁切、无重叠。

## 验证契约

- 完整门禁必须通过 lint、dependency lint、format、三个 tsconfig、全部 Vitest、构建、全量布局场景、
  四主题视觉、控件主题、真实 ConPTY、Windows 集成用例、加速 24 小时 soak 与正式发行编排。
- 必须使用 computer use 操作真实 Electron 窗口，独立切换并保存两个开关，检查标准与窄窗口设置层级、
  启动连接遮罩、输入锁、动效和无重叠；仅代码、jsdom 或自动截图测试不能替代。
- 最终安装包、blockmap 与 `rc.yml` 必须来自同一 exact commit 和 build cohort；COS 先发布不可变资产，
  最后推进 no-cache 的 `rc.yml`，再从真实安装的 rc.22 完成检查、下载、静默安装、自动重启和 rc.23
  版本确认。

测试数量、产物大小、SHA-256、cohort 与 Authenticode 状态只取最终候选日志和
`outputs/release-manifest.json`，不在构建前写死。

## GitHub Release 摘要 / Summary

**中文**

本候选版让 ClaudeDock 启动时真正接回上次对话的完整模型接入，拆分自动加载对话与模型，增加连接遮罩、
终端输入锁，并重整通用设置层级。

**English**

This release candidate reconnects the last conversation's complete model identity at startup, separates automatic
conversation and model loading, locks terminal input while connecting, and reorganizes General Settings.
