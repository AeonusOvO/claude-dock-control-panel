# ClaudeDock 5.0.0-rc.38

## 变更

- 活动栏“接入”改名为“模型”，图标跟随已成功接入的平台；内置全部支持品牌的本地 SVG，中转站保留链路图标。
- 当前接入右侧新增主题化额度/用量卡片。订阅显示可验证的剩余窗口额度，不支持读取的平台显示“暂无法获取”。
- API 显示自本次成功接入以来已记录的输入、输出和缓存 Token。重复记录去重，重连重新计数，重启保留统计。
- 增加可拖动、始终置顶的悬浮球，与主卡片和四套主题同步，主窗口隐藏后仍可查看。
- 使用独立后台 Worker、增量读取和合并信号；订阅查询低频单飞，不占终端输出热路径。

## 验收契约

- 图标覆盖全部预设、草稿/失败不变、启动恢复与资源损坏回退；按确切清单校验打包的 15 个 SVG 与授权。
- 统计覆盖时间起点、去重、缓存、子代理、截断/半行、越界路径、跨账户迟到结果和重启恢复。
- 真实 Electron 验证四主题、置顶、关闭/重开、受限 preload 与后台大文件读取时的主线程延迟。
- 无稳定接口、无匹配账号或无报告时不伪造额度；夹具不代表真实付费账户验收。
- 完整门禁与发行编排后 GitHub/COS 使用同一最终 cohort；应用内发现、下载、安装和重启验收完成前不标全部交付完成。

范围和限制见[模型额度与用量](../reference/model-usage.md)。

## GitHub Release 摘要 / Summary

模型页现在随接入平台显示品牌图标，并提供额度/Token 卡片和置顶悬浮球。后台增量统计、去重和账户隔离，
不支持读取的平台明确显示“暂无法获取”。

The Models tab follows the connected provider's locally bundled icon. A themed quota/token card and optional
always-on-top widget share background snapshots. Incremental worker-based accounting isolates connection epochs
and deduplicates reports; unsupported quota sources are explicitly unavailable.
