# ClaudeDock 5.0.0-rc.46

## 变更

- 打开、切换和关闭项目时，按规范化路径保留重音差异。关闭活动对话后，从可见对话中选取下一项。
- Claude 历史列表、改名和删除核对转录所属项目。同步与异步入口共享 JSONL 解析逻辑，异步读取继续定期让出主线程。
- 合法长路径的草稿可在重启后恢复，读取时隔离损坏的会话记录。
- 切换到原生对话前，同一代终端的停止重试会继续等待实际退出确认。
- 用量悬浮球加载期间的并发显示请求共享加载结果。
- 加速长时验证以实际完成的模拟分钟数判定，通过时记录累计模拟时长。
- 隔离运行配置在 CLI 网络预检之前拦截真实启动请求。

## 验收

最终提交执行完整发行编排、Windows 集成用例和 Electron 验证。同批安装包、blockmap 和 RC 清单通过公开对象复核后，由上一版本客户端执行检查、下载、安装及重启验证。
