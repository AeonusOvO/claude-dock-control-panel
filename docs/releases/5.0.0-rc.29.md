# ClaudeDock 5.0.0-rc.29

发布日期：2026-08-26

## 变更

- 启动时恢复最近一次选择的平台和模型改为 main 进程托管的后台事务；接入页会立即置灰、模糊并显示真实步骤，切换页面再返回也不会丢失进度或重复启动。
- 默认 2 分钟后显示“取消接入”，5 分钟后强制中止；两个阈值可在设置中自定义，主进程会校验范围与先后关系。
- 取消、超时和真实连接失败都经过同一份 abort/回滚边界；只有旧事务完全退栈才解锁界面，原接入保持不变，退出确认也会列出这项正在进行的工作。
- ChatGPT 账号的正常异步发现不再显示“账号信息暂不可用”：加载期明确写“正在读取账号与本机网关状态”，只有真实失败才显示可重试的错误。
- 自动接入使用不可见、不启动 PowerShell/ConPTY 的临时 owner，不会在“项目与对话”创建幽灵行、抢占当前对话或阻塞 renderer 事件循环。

## 验证门禁

- 单元回归覆盖主进程取消/硬超时、临时 owner 隔离、旧偏好迁移、设置校验、页面切换状态续接、失败 UI 回退与 ChatGPT 账号加载语义。
- 完整门禁必须通过 lint、dependency lint、format、三个 tsconfig、全部 Vitest、构建、布局、控件主题、四主题视觉、加速 24 小时 soak 与 `npm run dist`。

## GitHub Release 摘要 / Summary

**中文**

本候选版把冷启动模型恢复改为可观测、可取消、有硬截止且会安全回滚的主进程事务。接入页始终显示真实进度，ChatGPT 正常账号发现不再被误报为不可用。

**English**

This release turns startup model restoration into an observable, cancellable, hard-bounded main-process transaction with rollback-safe ownership. The connection page now preserves truthful progress across navigation, and normal ChatGPT account discovery is no longer presented as an unavailable account.
