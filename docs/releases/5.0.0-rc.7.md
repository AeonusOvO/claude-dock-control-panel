# ClaudeDock 5.0.0-rc.7

发布日期：2026-08-08

## 修复

- 修复原生 Claude 会话处于“仅预批准”（SDK `dontAsk`）时，用户明确要求选项仍被告知
  `AskUserQuestion` 不可用的问题。普通未预批准工具继续直接拒绝；只有当前提示词明确要求选择题或
  选项时，允许一次结构化选择卡，不需要切换到规划模式。
- 恢复原生会话权限栏中的“完全允许”。该选项只在项目“允许「完全允许」模式”预置开启时显示，
  启动、运行中切换和 adapter 都会独立校验门禁；默认开启预置不会自动进入高风险模式。
- 将原生权限标签“不主动询问”更正为“仅预批准”，并补充每种权限模式的可访问说明。

## 安全边界

- ClaudeDock 对严格模式的兼容层仅为用户明确请求的 `AskUserQuestion` 建立一次性例外，不放行 Bash、
  文件编辑、MCP 或其他权限请求。
- “完全允许”的项目许可不会写入恢复日志；恢复旧会话时仍以项目当前开关为准。

## 回归覆盖

- 覆盖主动提问拒绝、显式选项请求放行、同轮第二次提问拒绝和普通工具继续拒绝。
- 覆盖完全允许能力的显示、SDK 高风险预置、项目关闭时拒绝以及主进程运行中复核。
