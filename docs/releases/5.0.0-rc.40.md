# ClaudeDock 5.0.0-rc.40

发布日期：2026-08-28

## 变更

- 修复 ChatGPT 订阅已接入但额度依赖另一套 Codex 登录的问题；直接使用当前托管账户及工作区
  查询订阅窗口，不要求独立安装或登录 Codex，不重新授权，不用 Token 数或套餐名称推算额度。
- 额度卡片和悬浮球显示实际返回窗口的剩余百分比、重置时间和更新时间。网络、超时、授权失效、
  请求受限、账户切换及接口不兼容分别提示；无法读取时仍显示“暂无法获取”。
- 同一账户暂时查询失败时保留并标注旧数据；换号、同邮箱切换工作区、退出或授权事务期间清除
  旧额度，取消请求并拒绝迟到结果，避免显示其他账户数据。
- 后台查询有界、低频且可取消；不增加终端输出处理，不启动额外 CLI 或 PowerShell，不修改
  用户原有授权文件，不把令牌、账户 ID、邮箱或原始响应传到界面。

## 验证门禁

- 覆盖独立 Codex 不存在、当前托管账户/工作区匹配、令牌轮换、授权事务、文件链接及大小限制、
  服务器异常、响应截断/超限、超时取消和跨账户迟到响应。
- 真实 Electron 回环冒烟验证生产网络适配器、单一窗口、取消释放、主线程延迟和授权文件不变；
  同一脚本可从最终 ASAR 加载生产模块，不访问真实账户或执行模型请求。
- 最终候选执行全部质量门禁、真实 Electron/Windows 集成、24 小时加速 soak、正式 NSIS 打包与
  完整发行编排，并复核同批安装包、blockmap 与 rc.yml。
- 固定官方 HTTP 用量端点是兼容适配，不声称官方承诺其永久稳定。单账户只读查询不能替代所有
  套餐、令牌刷新或生产客户端安装验收；不使用 computer-use 自动安装或重新授权。

## GitHub Release 摘要 / Summary

**中文**

ChatGPT 订阅额度现在直接关联 ClaudeDock 当前托管账户，不再依赖另一套 Codex 登录。
后台低频读取真实窗口额度，明确区分失败原因，并隔离账户切换与迟到响应。

**English**

Reads ChatGPT subscription quota using the account already managed by ClaudeDock, without requiring
a separate Codex installation or login. Bounded background queries report real quota windows and
specific failures, preserve stale data only for the same account, and fence account/workspace changes.
