# ClaudeDock 5.0.0-rc.8

发布日期：2026-08-08

## 变更

- 将 Claude 的“新建安全会话”“继续最近”“选择历史”和历史记录点击统一改为
  PowerShell/ConPTY 安全终端主路径。
- 将结构化原生对话改为显式次级入口：终端工具栏显示“原生对话”，进入后同一按钮显示“返回终端”。
- 原生恢复记录不再自动打开原生界面或抢占终端；用户显式进入原生对话后仍可处理恢复卡。
- 新增根目录 `staged-repair-prompts.md`，整理缺陷修复总控提示词、阶段 0～12 和三个动态复现候选，
  可供分阶段实施与验收。

## 安全边界

- 本次只调整 renderer 的 presentation/runtime 路由，不修改 permission mode 默认值、
  `allowBypassPermissions` 项目门禁、Agent SDK 权限映射或 main/preload/shared IPC contract。
- 从原生对话返回安全终端继续复用单 owner、草稿确认、精确 UUID 恢复、附件保全和失败回滚事务。
- ClaudeDock 仍只解析用户本机安装的 Claude Code，不在安装包中捆绑第二份 `claude.exe`。

## 回归覆盖

- renderer contract 覆盖侧栏、工作台 new/continue/resume、历史恢复、显式原生 toggle 和恢复卡可见性。
- 真实 Electron 视觉流程先验证主按钮保持原生界面关闭，再显式打开原生对话并继续权限、提问、计划、
  MCP、主题和返回终端场景。
- fixture 视觉矩阵同步验证“返回终端”文案，同时保留四主题、窗口尺寸、缩放和交互中间帧覆盖。
