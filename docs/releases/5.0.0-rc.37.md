# ClaudeDock 5.0.0-rc.37

## 变更

- 修复接入页因终端状态更新而重建国产模型选择框，导致菜单反复关闭的问题。
- 修复国内订阅将本机转发地址误判为公共域名 DNS 失败；预检检查实际平台地址，保留原有网络守卫。
- API、Claude、ChatGPT 与国内订阅成功接入后统一弹出“模型已连接”，页面立即返回模型选择步骤。
  已实测成功的历史接入使用相同交互；仅恢复配置而未验证连接时不会弹出成功框。
- 当前接入增加“订阅 / API”标识。国内订阅账户从授权结果安全投影并随账号绑定保存，国内外订阅统一显示账户。
  官方未返回账户或旧绑定缺少该字段时显示“账户信息暂不可用”。
- 保留失败草稿、取消及重复回调的保护；测试费用说明仍为“可能会消耗少量 token”。

## 验收契约

- 回归覆盖全部五个国内账号入口的预检目标、自定义目标不被替换，以及已有本机绑定保持不变。
- 渲染交互覆盖连续终端状态更新时菜单不被替换，成功提示只由已完成操作触发，失败与旧回调不误报。
- 账户回归覆盖白名单与凭据过滤、加密保存、账号隔离、候选不展示、重启读取及令牌刷新绑定。
- Electron 视觉检查覆盖成功弹窗、当前接入类型与账户显示；测试夹具不代表真实付费账号授权或套餐抵扣验收。
- 最终候选需通过完整门禁、NSIS 发行编排、GitHub/COS 同批产物和公开摘要复核。
  真实应用内发现、下载、安装与重启验收完成前，不标记为全部交付完成。

实现及订阅支持范围见[订阅账号接入](../reference/subscription-access.md)。

## GitHub Release 摘要 / Summary

**中文**

修复国产模型选择框反复刷新关闭和国内订阅的本机 DNS 误报。统一接入成功提示与返回行为，
当前模型显示订阅/API 和安全账户信息。

**English**

Fixes domestic model menus closing during state refreshes and incorrect localhost DNS failures for subscription relays.
Successful connections return to model selection with one confirmation dialog. The current connection shows its
subscription/API type and safely projected account information when available.
