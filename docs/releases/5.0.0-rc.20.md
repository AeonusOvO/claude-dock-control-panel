# ClaudeDock 5.0.0-rc.20

发布日期：2026-08-25

## 变更

### 接入来源布局

- 拉开“选择模型来源”说明与四个入口卡片之间的响应式语义间距；窄窗口适度收紧，仍保留清晰文字层级，
  不再让说明文字贴住入口。
- 接入页右上角新增“接入历史记录”入口，按钮字号、图标、焦点态和主题表面与现有控件体系一致。

### 连贯操作胶囊

- “上一步 / 当前状态 / 下一步”胶囊在步骤切换时保持为同一个视觉对象；页面重排前后测量屏幕位置，
  再直接平移到下方目标位置，不随步骤内容重新淡入或闪烁。
- 位移只使用 compositor transform 和主题弹簧曲线；快速往返会取消旧动画，减少动态效果时直接落位。
  宽窄窗口均保持实时高斯模糊、统一按钮字号、触控高度和完整边缘余量。

### 分类接入历史

- 第二步“选择历史配置”只显示当前来源的记录：Claude 官方订阅、ChatGPT 官方订阅、国产模型与
  API / 中转站互不混排；切换来源不会删除或覆盖完整历史。
- 完整历史弹窗使用四个横向分类和左右弹簧位移，支持鼠标、方向键、Home / End；宽屏双列、窄屏单列，
  背景使用当前主题的实时高斯遮罩。
- 恢复、重命名、删除和右键菜单在内联区与弹窗中共享同一项目级存储和忙态；模态打开时右键菜单进入
  同一顶层，避免被遮罩或边缘裁切。

## 验证契约

- 完整门禁必须通过 lint、dependency lint、format、三个 tsconfig、全部 Vitest、构建、全量布局场景、
  四主题视觉、控件主题、加速 24 小时 soak 与 `npm run dist`。
- 最终安装包、blockmap 与 `rc.yml` 必须来自同一 exact commit 和 build cohort；COS 先发布不可变资产，
  最后推进 no-cache 的 `rc.yml`。
- 必须从实际安装的 rc.19 使用右上角“检查更新”发现 rc.20；检查本身不得下载，点击一次“下载并更新”
  后应完成下载、校验、静默安装、自动重启和版本确认。

测试数量、产物大小、SHA-256、cohort 与 Authenticode 状态只取最终候选日志和
`outputs/release-manifest.json`，不在构建前写死。

## GitHub Release 摘要 / Summary

**中文**

本候选版优化接入来源间距与跨步骤玻璃胶囊动效，并新增按 Claude、ChatGPT、国产模型和中转站分类的
项目接入历史；完整历史弹窗支持四主题、高斯遮罩、键盘切换和窄屏单列布局。

**English**

This release candidate improves access-source spacing and gives the glass wizard capsule continuous spring motion
across steps. It also adds source-filtered inline history and a responsive, theme-aware history dialog grouped by
Claude, ChatGPT, domestic models, and relay/API connections.
