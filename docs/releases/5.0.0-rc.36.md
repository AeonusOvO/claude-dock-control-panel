# ClaudeDock 5.0.0-rc.36

## 变更

- 国产模型列表增加“订阅 / API”胶囊。Kimi Code、MiniMax 国内及国际订阅新增“登录并连接”，不要求填写网址或密钥。
- GLM 国内及国际增加实验性浏览器授权入口，授权后创建或复用 ClaudeDock 专用密钥，并先确认套餐额度。
  千问保留套餐密钥接入；官方旧 OAuth 已停用，不提供无效的免密钥入口。
- 国内授权与原生接口转发在主进程后台运行，不弹出代理或 CC Switch 界面。保留“高级设置 / 极简设置”和手动密钥回退。
  测试说明保持“可能会消耗少量 token”。
- 新增加密凭据库、每次登录的独立会话绑定及并发令牌刷新协调。取消、迟到回调、重复点击与退出不能覆盖后来配置。
- 国内订阅、ChatGPT 全局授权与普通 API 写入共用配置事务边界，避免后台授权过程中被另一接入操作抢写。

## 验收契约

- 覆盖设备授权、PKCE/state、GLM 回环回调与套餐检查；错误数据、未知官网地址和无套餐时停止。
- 真实回环服务覆盖固定端口、账号隔离、SDK beta/模型路由、SSE、并发刷新、单请求断开、401 与退出。
- 真实 Electron 检查订阅/API 标签与无密钥登录界面，不使用用户账户或付费服务。
- 匿名授权初始化验证不等于付费套餐验收。GLM 上游授权提案尚未合并；真实账号登录、套餐抵扣及长期刷新仍需用户本人授权验证。
- 最终候选需通过全部门禁、完整发行编排、COS 通道与远端复核，并完成真实应用内发现、下载、安装验收；此前不得标记为交付完成。

实现、官方依据和验证限制见[订阅账号接入](../reference/subscription-access.md)。

## GitHub Release 摘要 / Summary

**中文**

新增 Kimi Code、MiniMax 订阅账号登录和实验性 GLM 浏览器授权；国产模型区分订阅/API，后台代理无需用户管理。
加固并发登录、取消、令牌刷新和会话隔离。千问仍使用官方支持的套餐密钥。

**English**

Adds Kimi Code and MiniMax account authorization, experimental GLM browser authorization, and subscription/API labels.
An embedded background relay protects credentials and coordinates login, cancellation, token refresh, and session bindings.
Qwen Coding Plan retains its supported subscription-key flow.
