# ClaudeDock 5.0.0-rc.34

## 变更

- “接入”和独立对话的模型设置默认只保留必填项；自定义填网址与密钥，内置国内服务只填密钥。
  “高级设置 / 极简设置”原位切换，保留草稿；改过的自定义网址不会因收起设置而被覆盖。
- 默认测试说明精简为“可能会消耗少量 token”。协议、认证与模型细节放进高级设置和文档。
- 自动补全地址，发现模型，并验证 Messages、Chat Completions 或 Responses；收到有效响应后才保存。
  测试预算与超时受限，失败不覆盖原配置，不跨站尝试密钥，不把 HTTP 200 或 HTML 页面当作连接成功。
- 独立对话支持 Responses 的正文、推理摘要、拒绝、完成状态与 Token 用量，并使用与实际对话一致的网络作用域。
- 补充千问、GLM、方舟、阶跃、腾讯 TokenHub、百度千帆及讯飞 API 预设；编程套餐与普通 API 分开。
  同步官方文档与订阅使用边界，不提取网页登录令牌或伪装客户端复用套餐。

## 验收契约

- 自动检测覆盖省略 scheme/后缀、不同协议与认证、租户前缀、错误密钥、无模型目录、额度不足、限流、取消与真实回环 HTTP。
- 验证先测试后保存、只测不存、失败保留旧配置、同源凭据隔离、串行提交、会话快照及表单切换。
- 真实 Electron 使用可命中的按钮检查极简/高级显示及国内网址隐藏，生成截图，不向外部模型发送测试密钥。
- 最终候选必须完成 lint、格式、类型、全量测试、依赖、Electron/ConPTY/网络与发行编排。COS 通道发布、
  远端复核及真实应用内发现、下载、安装验收完成前，仍为待发布。

## GitHub Release 摘要 / Summary

**中文**

极简模型接入：自动补全网址并识别协议，国产服务预填地址，高级设置保留完整手动选项。
缩短说明，增加 Responses 对话支持，区分官方编程套餐与普通 API。

**English**

Simpler model setup with automatic endpoint and protocol detection, domestic provider defaults,
and expandable manual settings. Adds Responses chat support and separates coding plans from ordinary APIs.
