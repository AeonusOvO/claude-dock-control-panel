# ClaudeDock 5.0.0-rc.28

发布日期：2026-08-26

## 变更

- 修复无项目 ChatGPT 一键接入在第 8 步回滚成“尚未选择接入”：全局安装、模型切换与内部真实请求现在
  共享同一个精确的下个对话 profile 网络授权身份，同时保留跨项目、跨 Provider 与跨目标的安全拒绝。
- 将受管 CLIProxyAPI 的 Windows 冷启动身份捕获与最终所有权确认预算从 2 秒提高到 5 秒，避免正常的
  PowerShell/CIM 查询偶发超时后误报“启动进程身份无法确认”。
- 接入失败仍保持事务性回滚：原下个对话 profile、模型摘要和控件状态不变，错误会明确显示，不产生
  “UI 看似成功、后台实际失败”的残留状态。

## 验证门禁

- 回归覆盖无项目一键安装与全局模型切换使用完全相同的 profile/application 预检身份，以及运行时内部
  readiness 验证接收该精确身份。
- Windows 进程身份测试锁定 5 秒默认预算，并继续验证出生时间、可执行路径、命令行、端口和连接五类
  所有权边界不被放宽。
- 完整门禁必须通过 lint、dependency lint、format、三个 tsconfig、全部 Vitest、构建、布局、控件主题、
  四主题视觉、加速 24 小时 soak 与 `npm run dist`。

## GitHub Release 摘要 / Summary

**中文**

本候选版修复 ChatGPT 一键接入在网关和模型均已就绪后仍于最终验证回滚的问题，并加固 Windows 冷启动
进程身份核验，避免正常 CIM 延迟造成误失败。

**English**

This release fixes projectless ChatGPT setup rolling back after the gateway and model catalog are already ready by
using one exact next-conversation authorization identity throughout the transaction. It also hardens Windows cold-start
process verification against normal PowerShell/CIM latency without relaxing ownership checks.
