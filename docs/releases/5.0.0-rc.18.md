# ClaudeDock 5.0.0-rc.18

发布日期：2026-08-25

## 变更

### 启动引导

- 首次使用改为“选择引擎 → 选择模型 → 自动准备 → 打开项目 → 准备完成”五步；Claude Code / Codex
  引擎与模型来源不再捆绑。
- Claude Code 引擎标题右侧增加紧凑“推荐”标签；Claude 官方订阅、ChatGPT 官方订阅、国产模型和 API
  使用统一文字层级与按钮字号。
- 国产模型选中后在卡片下方展开小选择框，支持 DeepSeek、通义千问、智谱 GLM、Kimi、MiniMax 与豆包，
  并明确显示当前选择。
- onboarding storage/flow 升级为 v2；rc.17 的合并路径选择确定性迁移，已完成用户不会重新弹出引导。

### 两步接入

- 接入页顶部新增“选择模型 → 配置与验证”进度条；首屏收敛为四个入口，不再要求普通用户浏览六组完整
  provider 目录。
- 第二步保留原有官方登录、ChatGPT 受管网关、国产/API 凭据、模型、历史、Router、cURL、真实测试与
  保存能力，并固定提供上一步和下一步。
- OpenAI 浏览器授权等待阶段可以由“上一步”自动取消；Proxy API 配置、模型发现、连接测试、修复和保存
  阶段禁用返回并显示不可打断原因。renderer 与 main 进程同时校验事务阶段和 session scope。

### 主题、动效与自适应

- 两个向导使用前进/返回对称的非线性空间动效，遵循从选择页进入、沿原方向返回的上下文关系。
- 四个主题继续通过语义 token 完整适配字体、表面、圆角、阴影、状态与 motion；720px 窄窗口切换为
  单列卡片和紧凑进度条，同类按钮保持统一 caption 字号和高度。

## 验证契约

- 完整门禁必须通过 lint、dependency lint、format、三个 tsconfig、全部 Vitest、构建、布局、主题、视觉、
  加速 24 小时 soak 与 `npm run dist`。
- 最终安装包、blockmap 与 `rc.yml` 必须来自同一 exact commit 和 build cohort；COS 先发布不可变资产，
  最后推进 no-cache 的 `rc.yml`。
- 必须从实际安装的 rc.17 使用右上角“检查更新”发现 rc.18，并复核下载链路；未完成远端与实际客户端验收
  前不得标记为用户可更新。

测试数量、产物大小、SHA-256、cohort 与 Authenticode 状态只取最终候选日志和
`outputs/release-manifest.json`，不在构建前写死。

## GitHub Release 摘要 / Summary

**中文**

本候选版将首次引导拆为独立的引擎与模型选择，并把接入页重构为两步向导；国产模型使用紧凑选择框，
ChatGPT 授权支持安全取消，Proxy API 与保存阶段具有明确的不可打断边界。

**English**

This release candidate separates engine and model choices in onboarding and introduces a two-step access wizard,
with a compact domestic-model picker, cancellable ChatGPT authorization, and explicit non-interruptible Proxy API
and save boundaries.
