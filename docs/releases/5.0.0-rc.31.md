# ClaudeDock 5.0.0-rc.31

发布日期：2026-08-27

## 变更

- 修复同一项目连续新建或恢复对话时，自动网络预检互相取消、导致先前标签被回滚删除的问题。自动检查
  共享相同目标的进行中检测，并保持每个会话独立的取消与访问授权。
- 对话编号改为按项目单调递增，关闭或启动失败不再导致两个“对话 2”。后台完成不会使用旧快照抢回焦点。
- 历史恢复不再修改或整份回滚共享列表；并发恢复、取消和迟到的历史扫描不会互相覆盖。多个模型差异
  弹窗依次处理，已经打开的历史对话不会被旧扫描重新显示为可恢复项。
- 会话独立接入配置只锁定自身 scope，同项目不同对话可分别恢复原模型并独立提交或回滚；旧版共享项目
  配置仍保留目录隔离。改变下个对话接入不改写现有 DeepSeek 或 ChatGPT 对话的绑定。
- 修复 Electron 43 在上传结束后提前发出 close，被误认为没有收到响应的问题；受控跳转和响应流可以
  正常完成，避免 ChatGPT 官方订阅在进入 OpenAI 授权前被错误阻止。真实网络错误、截断和取消仍被识别。

## 验证门禁

- 回归覆盖十次快速点击及乱序完成、自动预检共享、对话编号、并发配置提交/回滚、历史缓存和模型决策队列。
- 真实 Electron loopback 测试覆盖十路延迟跳转与流式响应、HEAD、响应截断和上传结束后的取消。
- 完整门禁包括静态检查、全部 Vitest、真实 Electron 布局/控件/视觉/ConPTY、Windows 集成、加速
  24 小时 soak、完整发行编排与 NSIS 构建。正式交付还需 COS 通道发布、远端复核和真实应用内更新验收。

## GitHub Release 摘要 / Summary

**中文**

本候选版修复连续创建与恢复对话时的预检竞态、重复编号、共享历史回滚和配置锁冲突，并修复 ChatGPT
订阅授权前的 Electron 请求误判；各对话保留独立的接入与启动状态。

**English**

This release fixes concurrent conversation creation and restoration, duplicate numbering, shared
history rollback, and profile lock conflicts. It also fixes premature Electron request closure
being mistaken for a network failure before ChatGPT subscription authorization.
