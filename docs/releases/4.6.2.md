# ClaudeDock 4.6.2 发布说明

4.6.2 是 ClaudeDock 5.0 原生对话改造前的决策与安全基线版本。本版本不提前切换 UI、IPC、PTY
或会话运行架构。

## 变化

- 将根目录 `当前版本需改进的bug.md` 从候选方案与待确认项改写为已经确认的实施规格，覆盖原生
  Claude 对话、会话唯一所有权、异常恢复、图片、模型能力、当前对话摘要、终端诊断、更新遥测及
  四主题截图验收。
- 明确 Claude 先迁移到结构化 Agent SDK，Codex App Server 原生迁移后续实施；高级终端只作为用户
  明确进入的兼容入口，并与原生会话事务化交接所有权。
- 将 `js-yaml` 从 4.3.0 升级到 4.3.1，修复 GHSA-5p4m-2wfm-xmqj。
- 将 `mermaid` 从 11.16.0 升级到 11.16.1，修复 11.16.0 及更早版本的原型污染、CSS 注入和图表
  拒绝服务公告。

## 验证与发布边界

依赖更新后的完整 `npm audit` 报告 0 个漏洞。本地 `npm run dist` 产物仍只用于开发验证。未完成
受信任 Authenticode 签名、签名 release manifest、安装/卸载烟测与 GitHub/国内镜像双渠道门禁前，
不得描述为 4.6.2 正式稳定版。
