# ClaudeDock 5.0.0-rc.33

发布日期：2026-08-27

## 变更

- 关闭并归档会话时立即显示处理中状态并禁用相关按钮，避免确认弹窗消失后重复点击；后台刷新列表
  不会解除禁用。整项目关闭也提供相同保护，取消或失败后可以重试，其他项目继续正常使用。
- 工作区左栏的添加项目、快捷操作和托盘说明随列表高度上下移动；到窗口底部后保持可见，只让
  项目和对话列表滚动。取消固定高度上限，不压缩对话行，刷新列表时保留滚动位置。
- 列表伸缩、滚轮和终端滚动采用非线性减速。连续滚轮输入共享原有调度器并累计到逻辑终点，滚动条
  同步移动；反向滚动、拖动滚动条或切换滚动区域不会被旧动画拉回。减少动态效果设置同时作用于
  普通界面和终端。
- 列表频繁收到后台状态时保留正在进行的布局动画进度，避免不断重启同一动画；导航到步骤、字段、
  标签和下拉选项也使用非线性滚动。

## 验证门禁

- 回归覆盖关闭中重复点击、项目与子会话互斥、失败重试、列表重绘、动画重定向、滚动余量守恒、
  方向反转、滚动条接管、模态边界和减少动态效果。
- 真实 Electron / ConPTY 验证最大化下十一个终端的尺寸一致性、长列表到窗口底部后的内部滚动、
  列表减少后的底部操作区上移，以及关闭按钮的即时禁用。
- 真实滚轮测试核对可见命中区域、首帧边缘接续、非线性中间帧和最终位移；布局、主题与发行门禁
  随最终构建重新执行。交付还需 COS 通道发布、远端复核及实际应用内发现、下载、安装和重启验收。

## GitHub Release 摘要 / Summary

**中文**

关闭并归档立即显示进度并防止重复操作；工作区底部操作区随列表伸缩，到窗口底部后固定可见。
统一非线性滚动和终端缓动，保留快速连续输入与滚动条直接拖动的响应。

**English**

Shows immediate archive progress and prevents duplicate close actions. Workspace footer controls follow
the conversation list until reaching the window bottom. Adds nonlinear scrolling and terminal motion
while preserving rapid input, scroll chaining, and direct scrollbar dragging.
