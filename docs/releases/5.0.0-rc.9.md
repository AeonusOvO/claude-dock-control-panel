# ClaudeDock 5.0.0-rc.9

发布日期：2026-08-09

## 变更

- 安全终端不再向可见 PowerShell 写入完整内部启动串；新 PowerShell 在提示符出现前一次性捕获该脚本，PTY 绑定完成后只显示固定短触发词。
- 移除 Claude Code 启动参数 `--no-chrome`，恢复 Claude in Chrome 和浏览器能力的原生可用性。
- 移除重复的 CLI `--model` 参数；模型继续由会话专用 `settings.json` 和项目环境映射确定。
- 默认会话仍不附加系统提示词或子代理；只有用户显式开启“联网检索隔离”兼容开关时才保留相应扩展。

## 安全边界

- 解密后的凭据仍只通过当前 PTY 环境注入，不写入启动命令、临时 settings、xterm 输入或 PowerShell 历史。
- `--settings`、权限模式、continue/resume、受管环境清理、退出 marker、statusLine 和权限 Hook 均保持不变。
- 承载内部启动脚本的一次性环境变量会在 Claude 子进程启动前删除，不继续传入 Claude Code。

## 回归覆盖

- 覆盖默认和恢复启动不含 `--no-chrome` / CLI `--model`，并继续验证 Windows agents JSON、权限参数与 marker 转义。
- 覆盖 PowerShell 一次性捕获、环境删除、短触发执行与语法有效性。
- 覆盖普通启动和速度切换的完整内部命令仍保留精确 resume UUID。
