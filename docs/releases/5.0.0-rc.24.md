# ClaudeDock 5.0.0-rc.24

发布日期：2026-08-25

## 变更

### 项目 `+` 直接新建真实对话

- 移除“新建安全会话”入口；项目标题旁的 `+` 现在立即插入一个新对话，并在右侧显示“正在新建会话”。
- 每次点击都有独立 session 与后台启动 owner。同一项目快速点击十次会创建十个对话，切换或离开当前
  终端不会中断它们。
- “当前项目开发引擎”改为全局“新建项目开发引擎”。选择只决定下一次新建使用 Claude Code 还是
  Codex，不修改任何已经打开的项目或会话。

### 历史恢复与失败回滚

- 点击历史记录后，该行立即移动到进行中区域并显示“正在恢复”；canonical JSONL 始终保留在磁盘，
  软件异常退出后可通过重新扫描找回。
- 终端分配、模型恢复或 CLI 启动失败会撤掉临时状态、恢复原历史行并关闭精确临时终端。若自动关闭本身
  失败，左栏明确显示红色“恢复失败 / 启动失败 · 请关闭”，同时给出可操作错误，不再显示假成功或无限加载。

### 后台运行、交互锁与退出保护

- 会话准备基于异步续体运行；Codex 安装/登录只串行共享写入阶段，其他会话异步等待后继续，renderer 与
  终端交互线程不会被轮询或历史解析阻塞。历史索引改用异步文件 I/O 和分批让出事件循环。
- 准备目标会话时，composer、网络预检、工作台、原生切换、目标行编辑和下一次引擎选择按作用域置灰；
  其他项目的 `+` 仍可点击。
- 显式退出遇到新建/恢复事务时，全窗口置灰并显示居中收尾清单、当前阶段和强退后果。用户可返回软件、
  转到后台继续，或二次确认强制退出。

## 验证契约

- 快速新建覆盖 10 个并发点击与 10 个精确 session owner；新建/恢复覆盖成功、IPC 失败、CLI 失败、正常
  回滚和回滚失败五类结果。
- 完整门禁必须通过 lint、dependency lint、format、三个 tsconfig、全部 Vitest、构建、布局、控件主题、
  四主题视觉、加速 24 小时 soak 与 `npm run dist`。
- 安装包、blockmap 与 `rc.yml` 必须来自同一次最终构建；只有 COS 通道清单推进并用真实候选包完成右上角
  “检查更新”发现、下载和安装复核后，才能标记为用户可更新。

## GitHub Release 摘要 / Summary

**中文**

本候选版把项目 `+` 改成真正的可并发后台新建，修复历史恢复与失败回滚，引擎选择改为全局下一次新建
偏好，并加入会话级交互锁和退出收尾保护。

**English**

This release candidate turns each project `+` click into an independently owned background conversation, makes
history restoration reversible, changes engine selection into a global next-conversation preference, and adds
session-scoped interaction locks plus protected shutdown handoff.
