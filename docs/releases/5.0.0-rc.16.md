# ClaudeDock 5.0.0-rc.16

发布日期：2026-08-24

## 变更

### 网络预检

- 连接结论改由精确配置的 Anthropic、OpenAI/Codex 或自定义 Provider 端点证据决定，包括 DNS、TLS、HTTP、重定向、内容替换、应用会话、CLI 和动作要求的 WebSocket。
- 公网地址、DNS 对照、IPv6、STUN、接口、时区、语言和信誉来源改为带目标、进程、网络作用域、传输、地址族、时间、新鲜度与置信度的建议证据，不再称为模型或 Provider 出口。
- `resolveProxy() === DIRECT` 只表示当前目标未发现显式 HTTP/SOCKS/PAC 代理，不再用于证明物理直连；TUN、透明代理和按目标分流保持可见说明。
- 可用 Provider 即使存在 TUN、虚拟接口或建议项不可用，也保持绿色“连接正常”；只有精确 Provider 能力失败才降级或阻止对应操作。

### 终端输入

- `Ctrl+V` 和右键菜单粘贴统一为一次 generation-owned `Terminal.paste()`；xterm 继续负责换行规范化和 bracketed paste，`onData()` 是唯一 PTY 写入路径。
- 重复按键、异步剪贴板读取后的过期 session/view/PTY generation 和已替换菜单目标均被拒绝。
- 右键 `mousedown` 与 `contextmenu` 在 capture 阶段先于 Chromium/xterm 处理，TUI 开启鼠标跟踪时也只打开 ClaudeDock 菜单。

### 异步反馈

- Claude 启动明确显示“正在进行网络预检…”、“正在启动…”和等待确认阶段。
- 网络重检、插件刷新、开发引擎切换、终端启停重启以及 Codex 安装、更新、登录、取消、退出和启动均使用 operation-owned 文案、`aria-busy` 与 live status。
- 较旧操作的结果或 `finally` 不能解锁、覆盖或恢复较新的操作。

### 运行时标记

- Claude Code 使用本地官方 Anthropic Clay Spark；Codex 使用本地官方 OpenAI 黑/白 Blossom。
- 三个 SVG 保留官方 geometry、fill、来源 URL、检索日期和哈希，使用固定品牌表面，不通过主题 token 或 CSS filter 重着色。
- Vite 将标记输出为可检查的本地资源；运行时不访问外部图标服务。

### 仓库与打包

- 新增精简的贡献、安全、行为准则、Bug/Feature Issue 表单和 Pull Request 模板。
- `LICENSE` 与 `NOTICE` 成为 electron-builder `build.files` 的显式打包契约。

## 验证契约

全部发行源码、测试和文档提交后，本版本在该 exact commit 上按 [验证清单](../how-to/verify.md) 执行快门禁、
三项 opt-in Windows 集成测试、全部 Electron/ConPTY/soak 门禁和最终 `npm run release`。最终候选必须
额外确认：

- `outputs/release-manifest.json` 的问题列表为空，installer、blockmap 与 `rc.yml` 属于同一次构建；NSIS
  payload 与 `win-unpacked` 逐字节一致，blockmap v2 chunks 与 cohort evidence 有效。
- 最终 packaged application 包含 `LICENSE`、`NOTICE` 和三个本地品牌 SVG，且不包含第二个 `claude.exe`。
- GitHub 公开重新下载的三个资产与本地 manifest 字节一致。
- COS 版本化对象先发布，`rc.yml` 最后推进；公开长度、Range、缓存和完整摘要验证通过。

测试数量只取自 exact-commit 门禁日志；`release-manifest.json` 不记录测试数量。产物大小、
SHA-256/SHA-512、cohort 和 Authenticode 状态只取自最终候选的 `release-manifest.json`。两类事实都不在
最终候选运行前固化到仓库文档。
