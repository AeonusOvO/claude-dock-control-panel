# 接入模型

## 默认设置

在“接入”页选择服务商。带“订阅”标签的 Kimi Code、MiniMax 点击“登录并连接”，在官网完成授权即可；
GLM 的浏览器授权标为实验性。软件会在后台完成准备、测试和保存，不需要打开代理软件。

带“API”标签的服务填写密钥，点击“连接并保存”。自定义接口再填写网址；可以省略
`https://` 和常见接口后缀。独立对话右上角的模型设置使用相同方式，但配置互相独立。

可能会消耗少量 token

连接成功后才保存。更换网址时请重新填写对应的密钥。已保存的密钥不会回显，网址未变时留空可继续使用。

## 高级设置

点击“高级设置”展开网址、协议、认证和模型等手动选项；按钮变为“极简设置”，再点击即可收起。
切换不会清除草稿。在高级设置中改为非官方网址后，返回极简模式会保留为自定义接口。

服务商不提供可用模型列表时，在高级设置填写其控制台给出的模型标识，再测试连接。

## 官方套餐

千问 Coding Plan 仍需填写套餐密钥，官方旧 OAuth 已停用。其他订阅的高级设置也保留密钥入口。
GLM 浏览器授权会创建或复用 ClaudeDock 专用套餐密钥，取消后可在官网撤销。
普通 API 密钥选择“千问 API”“智谱 GLM API”等入口。网页聊天会员不等于 API 额度。

独立对话默认使用普通 API；不会读取网页 Cookie、导入网页登录令牌或伪装其他客户端。
各服务的地址、套餐范围与官方依据见[服务商接入参考](../reference/provider-access.md)和
[订阅账号接入](../reference/subscription-access.md)。授权期间可以取消；完成连接前不会替换已有配置。
