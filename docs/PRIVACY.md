# ClaudeDock 隐私说明

生效日期：2026-08-03

本说明适用于 ClaudeDock 4.0.0 及以后版本的 Windows 桌面应用。当前维护者为 Cheng / ClaudeDock
项目；隐私、数据删除和安全问题通过公开仓库的 GitHub Issues 联系：
<https://github.com/AeonusOvO/claude-dock-control-panel/issues>。正式发行前应补充持续有效的邮箱；
如果以后改由公司、团队或其他主体发布，必须先把本文和应用内主体信息改成真实名称、地址和联系方式。

## 处理原则

ClaudeDock 不要求注册 ClaudeDock 账号，不内置广告、用户画像或遥测，也不把用户输入发送给维护者
自建的分析服务。应用只为用户主动使用的本机管理、更新、软件安装、AI 接入和可选网络诊断处理必要
数据。项目以 Apache-2.0 开源和非商业履历项目为当前定位；是否收费不改变个人信息、网络或内容合规义务。

## 本机保存的数据

- 项目路径、应用偏好、终端会话元数据和用户创建的对话历史保存在当前 Windows 用户的 Electron
  `userData` 目录。
- AI 服务密钥和外部应用代理密码使用 Electron `safeStorage`，在 Windows 上由 DPAPI 保护；renderer
  只能看到“是否已配置”。代理地址、端口、协议、账号和作用域保存在
  `userData/proxy/application-proxy.json`，密码不以明文写入该文件。
- 网络预检历史最多保留 7 天或 40 条，公网地址只保存掩码网段。新安装默认开启增强隐私模式，不请求
  第三方公网出口情报。
- 4.0.0 不读取或启用旧版节点、订阅或 Xray 数据。升级不会擅自删除这些旧文件；不再需要时可在完全
  退出应用后删除 `userData/proxy/` 中除 `application-proxy.json` 外的旧版内容。

用户可以在应用中删除对话、项目记忆和诊断历史。卸载应用不会必然删除 Electron `userData`；如需
完全清除，应在退出应用后删除该目录。删除前请先导出需要保留的内容。

## 发生联网的场景

| 场景                        | 接收方                                                   | 可能发送的数据                                                                                      | 目的                                       |
| --------------------------- | -------------------------------------------------------- | --------------------------------------------------------------------------------------------------- | ------------------------------------------ |
| 应用更新                    | GitHub Releases；配置后还包括维护者的 HTTPS 镜像         | 当前版本、下载范围和常规 HTTPS 请求信息                                                             | 检查、测速、下载并校验 ClaudeDock 更新     |
| Claude Code / Router 更新   | Anthropic、WinGet、npm、npmmirror 或用户选择的官方发行源 | 软件包名、版本、最多 128 KiB 测速样本和常规 HTTPS 请求信息                                          | 查询版本、选择可用来源、下载安装           |
| AI 对话和 Claude/Codex 终端 | 用户主动选择的 Anthropic、OpenAI、第三方中转或本地端点   | 用户输入、附件、会话上下文及端点要求的认证信息                                                      | 返回用户请求的模型结果                     |
| 外部应用代理                | 用户填写或选择的代理运营者/管理员                        | 所选作用域请求的目标、流量元数据；HTTP CONNECT/SOCKS 转发下的具体可见内容取决于协议、TLS 和代理实现 | 转发用户明确勾选的 CLI、应用或独立对话网络 |
| 可选网络诊断                | 官方服务端点；关闭增强隐私时还可能访问出口情报服务       | DNS、TLS、连通性和必要的公网出口信息，不含 AI 登录令牌                                              | 判断所选服务是否可达                       |

更新测速不会调用模型。应用镜像每次最多采样 256 KiB；只有其 `latest.yml` 与 GitHub 公布的版本、
文件名和 SHA-512 完全一致才会参与下载选择。

第三方服务按其自己的条款和隐私规则处理数据。ClaudeDock 无法决定第三方的保存期限。请只选择可信
端点和有权使用的代理，不要提交无权处理的个人信息、商业秘密、国家秘密、未公开源代码或受监管数据。

## 外部应用代理边界

ClaudeDock 4.0.0 不提供、销售或导入代理节点和订阅，不下载或启动代理内核，不创建 VPN/TUN/透明
代理，不提供跨境线路或公网出口，也不修改 Windows 系统代理、DNS、路由表或网卡。它只把用户勾选的
进程流量指向一个已经存在的 HTTP/SOCKS5 地址和端口。该边界不代表任意代理服务或用途当然合法；
用户仍应确认其来源、授权和用途符合所在地法律、单位制度与服务条款。

## 跨境处理

GitHub、Anthropic、OpenAI、npm 以及用户选择的其他服务可能位于中国大陆以外。用户主动选择这些
端点时，应先确认自己有权发送相关内容。若发布主体以后提供自有 API、共享 Key、统一账号、云端历史，
或在业务中决定处理目的和境外接收方，还需重新评估个人信息保护法规定的告知、单独同意、处理者义务
和跨境机制，不能只依赖本说明。

## AI 生成内容

ClaudeDock 在独立对话区把模型回复标为“AI 生成”。生成内容可能不准确；涉及医疗、法律、金融、招聘、
公共传播或其他高影响用途时必须人工核验。用户不应删除依法必须保留的生成内容标识。如果以后由维护者
面向公众直接提供生成式 AI 服务，还需重新评估算法、安全、内容治理和文件元数据标识义务。

## 未成年人

ClaudeDock 面向能够管理开发工具和第三方服务凭据的用户，不以不满 14 周岁未成年人为目标。监护人
发现未成年人通过本应用提交了个人信息时，可通过上述渠道联系维护者处理。

## 安全事件与更新

维护者会通过 GitHub Release 和仓库安全公告发布安全更新。发现漏洞时请不要在公开 Issue 中粘贴密钥、
代理密码或可直接利用的细节；应使用仓库的私密安全报告渠道。隐私规则发生实质变化时，应在新版本发行
说明中突出说明，并在依法需要时重新取得同意。
