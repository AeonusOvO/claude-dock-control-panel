# ClaudeDock 隐私说明

生效日期：2026-08-03

本说明适用于 ClaudeDock Windows 桌面应用。当前维护者为 Cheng / ClaudeDock 项目；隐私、数据删除和安全问题通过公开仓库的 GitHub Issues 联系：<https://github.com/AeonusOvO/claude-dock-control-panel/issues>。如果后续改由公司、团队或其他主体发布，必须在发行前把这里和应用内的主体名称、地址、联系方式改成实际信息。

## 处理原则

ClaudeDock 不要求注册 ClaudeDock 账号，不内置广告、用户画像或遥测，也不会把用户输入发送给维护者自建的分析服务。应用只为用户主动使用的本机管理、更新检查、软件安装、AI 接入和可选网络诊断处理必要数据。

## 本机保存的数据

- 项目路径、应用偏好、终端会话元数据和用户创建的对话历史保存在当前 Windows 用户的 Electron `userData` 目录。
- AI 服务密钥、代理节点凭据等秘密使用 Electron `safeStorage`，在 Windows 上由 DPAPI 保护；其他本地记录仍受当前 Windows 账户和磁盘权限保护，不应把整个用户数据目录交给他人。
- 网络预检历史最多保留 7 天或 40 条，公网地址只保存掩码网段。新安装默认开启“增强隐私模式”，不请求第三方公网出口情报。
- Xray 临时配置只在启动内置代理时生成，停止后清理。ClaudeDock 不修改 Windows 系统代理。

用户可以在应用中删除对话、项目记录、诊断历史、代理节点和订阅；卸载应用后，如需完全删除数据，还应删除 ClaudeDock 的用户数据目录。卸载前请先导出需要保留的内容。

## 发生联网的场景

| 场景                        | 接收方                                                 | 可能发送的数据                                         | 目的                             |
| --------------------------- | ------------------------------------------------------ | ------------------------------------------------------ | -------------------------------- |
| 应用更新                    | GitHub Releases                                        | 当前版本、常规 HTTPS 请求信息                          | 检查、下载并校验 ClaudeDock 更新 |
| Claude Code / Router 更新   | Anthropic、npm、npmmirror 或用户选择的发行源           | 软件包名、版本和常规 HTTPS 请求信息                    | 查询版本、轻量测速、下载安装     |
| AI 对话和 Claude/Codex 终端 | 用户主动选择的 Anthropic、OpenAI、第三方中转或本地端点 | 用户输入、附件、会话上下文及端点要求的认证信息         | 返回用户请求的模型结果           |
| 可选代理订阅                | 用户填写的订阅服务                                     | 订阅请求和常规 HTTPS 请求信息                          | 下载并预览节点配置               |
| 可选网络诊断                | 官方服务端点；关闭增强隐私时还可能访问出口情报服务     | DNS、TLS、连通性和必要的公网出口信息，不含 AI 登录令牌 | 判断所选服务是否可达             |

第三方服务按其自己的条款和隐私规则处理数据。ClaudeDock 无法决定第三方的保存期限。请只选择可信端点，不要向模型或中转服务提交无权处理的个人信息、商业秘密、国家秘密、未公开源代码或受监管数据。

## 跨境处理

GitHub、Anthropic、OpenAI、npm 以及用户选择的其他服务可能位于中国大陆以外。用户主动选择这些端点时，请先确认自己有权把相关内容发送到该地区。若发布主体在业务中决定处理目的、集中收集用户内容或代用户选择境外接收方，发布主体还需另行评估个人信息保护法规定的告知、单独同意和跨境机制，不能只依赖本说明。

## AI 生成内容

ClaudeDock 在独立对话区把模型回复标为“AI 生成”。生成内容可能不准确；涉及医疗、法律、金融、招聘、公共传播或其他高影响用途时必须人工核验。用户不应删除依法必须保留的生成内容标识。

## 未成年人

ClaudeDock 面向能够管理开发工具和第三方服务凭据的用户，不以不满 14 周岁未成年人为目标。监护人发现未成年人通过本应用提交了个人信息时，可通过上述渠道联系维护者处理。

## 安全事件与更新

维护者会通过 GitHub Release 和仓库安全公告发布安全更新。发现漏洞时请不要在公开 Issue 中粘贴密钥或可直接利用的细节；先通过仓库提供的私密安全报告渠道联系。隐私规则发生实质变化时，应在新版本发行说明中突出说明，并在依法需要时重新取得同意。
