# ADR-0003 源码文本回归钉

- 状态：已被 [ADR-0009](0009-behavioral-tests-replace-source-pins.md) 取代
- 日期：2026-08-17

## 背景

`tests/` 里约 1,045 处断言用 `readFileSync` 读取源文件，再对文本做正则或子串检查。它们断言的是"这段代码写成了这个形状"，例如某个 CSS 选择器存在、某个 `await` 没被删掉、某个 CSP 指令包含特定值、某处调用带了特定参数。

这类断言测的是写法而不是行为，是公认的反模式。但当前渲染进程是 15,181 行的单一作用域：没有导出、没有模块边界，无法在测试里加载其中一部分并驱动它。写行为测试的前置条件不存在。

## 决策

保留源码文本断言，并明确它们的定位与边界。

**定位**：它们是回归钉，不是行为测试。用途是把已经修过一次的缺陷钉住——某个修复的具体代码形态被删掉时立刻失败。

**边界**：

- 一处断言必须对应一个真实发生过的缺陷或一条明确的结构约束，不为"提高覆盖率"新增。
- 不用它们替代可写的行为测试。当一段逻辑已经可以从模块导入并驱动，就写行为测试，不写文本断言。
- 删除任何一处必须在提交说明里给出理由。
- 输入从"单个文件的 `readFileSync`"改为 `tests/helpers/source-corpus.ts` 提供的"按目录递归拼接的语料"，使断言在代码搬迁到新文件后仍然命中。

**补齐行为侧**：`scripts/*-smoke.cjs` 在真实 Electron 里检查布局、四主题控件计算样式、原生 `<select>` 交互、ConPTY 尺寸与生命周期、视觉截图。渲染进程改动后手动打开对应界面确认往返正常。

## 结果

- 1,045 处回归保护在结构重组期间一处不丢。
- 语料化后，代码搬迁不需要逐条改断言路径。跨文件的多行正则是例外，需要单独修复。
- 代价：这些断言仍然对代码写法敏感。合法的重写（改用等价语法、重命名局部变量）会误报。误报时正确处理是更新断言，而不是回退重写。
- 代价：它们给不出行为保证。渲染进程按特性分片完成后，行为测试应逐步替代其中可替代的部分。

## 备选方案

**直接删掉，只留行为测试** —— 在渲染进程可分片加载之前，等于放弃 1,045 处已有的回归保护，且没有替代品。

**先写行为测试再重组** —— 行为测试的前置条件（模块边界）恰好是重组要产出的东西，顺序上不成立。
