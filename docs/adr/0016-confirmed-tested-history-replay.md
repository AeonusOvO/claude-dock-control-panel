# ADR-0016 先确认、实测后提交的历史接入事务

- 状态：已采纳
- 日期：2026-08-25

## 背景

分类接入历史最初把卡片点击直接连接到配置回放 IPC。用户没有独立确认机会；renderer 收到配置事务成功就
显示“恢复成功”，但 API / 中转站可能尚未通过网络、认证与模型响应测试。快速成功、失败和用户取消又会
落回普通两步向导，导致结果与当前接入身份不清晰。

## 决策

1. 历史卡片只建立选择。弹窗初始没有默认项，底部为“取消”；选择后显示当前名称、语义选中态和“完成”。
   内联卡、分类弹窗和右键恢复全部进入同一确认路径。
2. 确认后 renderer 切到独立历史接入 surface，隐藏并 inert 普通两步向导。该 surface 显示运行、正在取消、
   失败和成功四种结果；失败可重试，成功保留 1.5 秒后自动回落。
3. 主进程先准备候选配置，再用候选凭据执行真实最小 Messages 探针，最后才提交项目配置。API / 中转站的
   “完成”必须同时代表连通、认证和模型 envelope 通过；失败不提交。
   OpenAI 准备对 Router 的临时 Provider 写入随 prepared value 携带精确回滚；回滚前必须同时匹配原 CCR
   service identity 和服务端返回的 applied config，避免失败或取消覆盖用户随后保存的新 Router 配置。
   事务还在 commit 前保存项目配置快照；commit 或 complete 后失败、取消时，只有当前 session 仍指向原项目
   且磁盘状态仍是本事务写入的精确结果，才恢复项目快照并补偿 Router 外部状态。
4. Claude 官方现有登录的凭据仍归 Claude Code 所有，独立 Messages 探针不会读取或模拟令牌，因此该探针
   可以保留 warning。账号状态由主进程另行执行 `claude auth status --json`，清除 Provider 覆盖环境后只投影
   `loggedIn`、安全账号标识、认证方式和检查时间；未登录时从 CLI 退出码 1 所附的有界合法 JSON 明确显示
   “未登录”，命令缺失、超时或没有合法状态载荷时才降级为“账号信息暂不可用”。原始 JSON、令牌和其他
   未知字段不进入 renderer。
5. 取消 IPC 绑定历史事务拥有的 exact `AbortSignal`。主进程只取消同一 lease 并等待 unwind；不匹配返回
   `false`，renderer 保留真实结果，避免取消后来启动的其他终端操作。
6. renderer 的历史加载、应用、删除、重命名和恢复结果都由 `{ generation, sessionId }` 双重 fence 持有；
   切换项目立即使旧 owner 失效。主进程同时验证发起 session 仍映射到原规范化项目目录，迟到结果不能改写
   新项目，也不能解除新项目的 busy 状态。
7. 页面顶部的当前接入摘要只使用主进程已验证的配置视图、历史显示名称、受管 ChatGPT 账号和上述 Claude
   官方安全投影。URL 去掉 userinfo、query 与 fragment，API key 只显示是否已配置；状态命令不可用时明确
   降级，不用 Windows 用户名、项目名或其他字段猜测账号。

## 后果

- 历史恢复从“点击即写入”变为“选择—确认—实测—提交—展示结果”，快速 API 也有完整可见结果。
- 网络或认证失败、用户取消会在所有权仍匹配时恢复原项目配置和本事务准备的 Router 外部状态；若检测到
  较新写入则拒绝覆盖。跨项目迟到结果与同一 session 的其他终端工作都有可证明的所有权边界。
- renderer 增加一个专用恢复状态控制器，IPC 增加一个请求响应通道；`ControlPanelApi` 与频道总数均变为
  203。
- Claude 官方订阅不能由独立 HTTP 探针借用 CLI 令牌完成模型请求验证；这不等于账号完全不可获取。登录与
  账号摘要来自受限的 CLI 状态投影，并通过现有 `claude:state` 契约交付，不新增 IPC/API 成员。

## 验证

- main 测试验证候选连接测试发生在 commit 前、外部取消原因不被转换成普通网络失败、exact signal 才能
  取消 lease，并覆盖 prepare 后取消、测试失败时的项目配置与 Router 补偿、较新写入不被回滚、session
  已切换项目时拒绝提交，以及 Claude 状态命令的环境清理、白名单投影和失败降级。
- renderer 测试验证初始取消、选中提示与焦点状态、分类切换清空、专用运行界面、失败重试、成功延时
  回落、后台确认取消，以及加载、应用、删除、重命名在跨项目切换后的迟到结果被丢弃。
- Electron 布局与四主题视觉烟测检查历史弹窗、选中卡、当前接入摘要与专用结果页在全部断点无裁切、
  无遮挡，并由唯一 reduced-motion 规则收敛动画。
