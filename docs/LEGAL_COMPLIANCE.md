# ClaudeDock 中国大陆公开发行合规评估

评估日期：2026-08-03

这是一份产品风险清单和工程边界记录，不替代中国执业律师对发行主体、商业模式、服务器部署、实际用户和合同的正式法律意见。法律是否适用取决于真实运营方式；仅改按钮名称或加入免责声明不能改变功能实质。

## 当前结论

1. **应用内自动更新可直接使用 GitHub Releases，不强制自建服务器。** 当前 NSIS 构建已经接入 `electron-updater`，Release 需要同时公开 `latest.yml`、安装包和 blockmap。仓库目前是私有仓库，普通用户无法读取 Release；对外发布前必须把仓库转为公开，或改成公开可读的自建更新源。不能把私有 GitHub Token 放进客户端。
2. **国内无备案服务器不应作为公开更新服务的默认方案。** “浏览器能下载文件”不等于符合备案要求或长期可用。若通过中国大陆服务器的域名或 IP 向公众持续提供下载、API 或网站，应先由发行主体和接入商确认 ICP 备案/许可、公安联网备案及其他适用要求。未完成前优先使用境外服务器或公开 GitHub Release。
3. **当前通用代理模块是中国大陆公开发行的高风险项。** 它能导入任意节点/订阅并为 CLI、对话或应用形成用户可配置的网络出口，和只为自家远程桌面传输服务的 ToDesk 类专用中继不是同一种产品边界。“加速器”名称、回环端口、默认关闭或免责声明都不能消除未经批准建立/使用其他国际联网信道的风险。
4. **AI 客户端边界目前相对可控，但不能变成无治理的公共生成式 AI 服务。** ClaudeDock 当前由用户自行选择服务商和密钥，维护者不集中接收提示词。如果以后提供自有网关、共享 Key、统一账号、云端对话存储或面向公众直接提供生成服务，应重新评估生成式 AI 服务、算法备案/安全评估、内容治理和生成内容标识义务。

## 已完成的工程完善

- 新安装默认开启增强隐私模式；公网出口情报探测改为用户明确关闭该模式后才运行。
- 设置中加入持续可访问的隐私与合规页，列出本地保存、第三方接收方、跨境风险、权利渠道和代理风险。
- 独立对话的模型回复显示“AI 生成”。
- 应用自动更新由用户主动下载，安装前再次确认；更新器使用 `latest.yml` 中的 SHA-512 信息和 blockmap 校验下载。
- Claude Code npm 更新只对当前 npm 安装执行；用不超过 128 KiB 的样本比较 npm 官方源和 npmmirror。原生安装沿用官方更新器，避免在同一电脑生成重复命令。
- 代理测速取消 10 MB 大文件，采用和 v2rayN real-ping 同类的 HTTP 请求延迟方法，并强制经过 ClaudeDock 的独立 Xray 会话。没有复制、链接或分发 v2rayN GPL 源码。

## 代理模块需要发行者决定

推荐顺序如下：

1. **中国大陆公开版移除通用代理模块（推荐、最低风险）。** 删除节点/订阅导入、Xray 下载与通用出口作用域；其他国家或地区版本可在当地法律评估后单独发行。
2. **改成单位内部受控网络模式。** 只允许合同授权、依法取得的企业专线或 VPN；端点白名单固定为本单位业务系统，禁用公共订阅和任意节点导入，并保留管理员配置、用途控制和审计记录。仍需电信业务、网络安全和单位制度审查。
3. **保留当前通用代理模块（高风险，不建议）。** 即使加入提示、默认关闭、软件不提供节点，功能仍可能被用于跨境国际联网；这不是靠用户勾选“我已知晓”即可解决的风险。

在发行者作出选择前，本轮没有擅自删除现有模块，只在界面和文档中明确标记风险。

## 如果以后改用自建更新服务器，需要提供的信息

更新源不需要业务 API，但需要一个稳定的公开 HTTPS 静态目录。请提供：

- 更新域名、部署国家/地区、CDN/对象存储供应商和备案状态；
- 正式 HTTPS 基础地址，例如 `https://updates.example.com/windows/x64/`；
- CI 上传方式和最小权限凭据（只放 GitHub Secrets，绝不写进客户端）；
- Windows 代码签名证书的主体、PFX/Base64 Secret 名和密码 Secret 名；
- 是否需要灰度发布、回滚、国内/国外双源、最低支持版本和强制更新策略；
- 日志字段、保留时间、访问控制和隐私联系人；
- 预计用户量、单包大小、月流量、存储和 CDN 带宽预算。

服务器必须满足：

- `latest.yml` 短缓存或 `Cache-Control: no-cache`；版本化安装包和 blockmap 可长缓存；
- 公开匿名 GET/HEAD，支持 HTTPS、Range 请求和正确的 `Content-Length`，不依赖 Cookie、网页验证码或登录跳转；
- 同一版本目录原子发布 `latest.yml`、`ClaudeDock-Setup-<version>-x64.exe` 和对应 `.blockmap`，不能先发布元数据再慢慢上传安装包；
- 保留至少一个可回滚版本，监控 4xx/5xx、校验失败和下载完成率；
- 安装包必须使用稳定的 Windows 代码签名身份。首次外发前建议使用受信任代码签名证书并保护私钥。

GitHub 与自建源都可以工作。GitHub 的优点是无需维护更新服务器、Release 与 CI 集成简单；缺点是中国大陆网络质量不稳定。自建境外源便于国内外双 CDN 和日志控制，但需要承担证书、带宽、监控、数据与合规责任。

## 主要官方依据

- 《中华人民共和国计算机信息网络国际联网管理暂行规定》：国际联网应使用国家公用电信网提供的国际出入口信道，不得自行建立或使用其他信道。司法部法规库：<https://xzfg.moj.gov.cn/mobile/law/detail?LawID=1147>
- 工业和信息化部《关于清理规范互联网网络接入服务市场的通知》：未经批准不得自行建立或租用专线（含 VPN）等信道开展跨境经营活动；国际专线用途有明确边界。<https://www.miit.gov.cn/zwgk/zcwj/wjfb/tz/art/2017/art_a940645e940946e1a62cd6c90a4e994e.html>
- 《互联网信息服务管理办法》及非经营性互联网信息服务备案规则：经营性服务实行许可，非经营性服务实行备案。工业和信息化部：<https://www.miit.gov.cn/gyhxxhb/jgsj/cyzcyfgs/bmgz/xxtxl/art/2024/art_84a0cfa0ebd049bbbe751dca9a008e56.html>
- 《中华人民共和国个人信息保护法》：处理前告知、最短保存期限、个人权利和向境外提供个人信息等要求。全国人大：<https://www.npc.gov.cn/WZWSREL25wYy9jMi9jMzA4MzQvMjAyMTA4L3QyMDIxMDgyMF8zMTMwODguaHRtbD9yZWY9aW1i>
- 《网络数据安全管理条例》（2025-01-01 起施行）：网络数据安全制度、漏洞处置、投诉渠道、个人信息规则和合规审计要求。司法部法规库：<https://xzfg.moj.gov.cn/front/law/detail?LawID=1734&Query=>
- 《生成式人工智能服务管理暂行办法》：适用于向中国境内公众提供生成式 AI 服务的情形，内部研发且不向公众提供服务不适用。国家网信办：<https://www.cac.gov.cn/2023-07/13/c_1690898327029107.htm>
- 《人工智能生成合成内容标识办法》（2025-09-01 起施行）：对适用的服务提供者规定显式标识和文件元数据标识。国家网信办：<https://www.cac.gov.cn/2025-03/14/c_1743654684782215.htm>
- 《促进和规范数据跨境流动规定》：对部分场景简化申报机制，但不免除个人信息告知、合法性和安全保护义务。国家网信办：<https://www.cac.gov.cn/2024-03/22/c_1712776612187994.htm>

## 发布前仍未完成的事项

- 发行主体的法定全称、地址、有效邮箱/电话尚未提供；如不是 Cheng 个人发布，必须替换应用和隐私说明中的主体信息。
- GitHub 仓库仍为私有，公开用户无法使用当前更新通道。
- Windows 安装包尚未配置受信任代码签名证书；无签名包会出现未知发布者/SmartScreen 风险，不宜直接大规模外发。
- 代理模块的中国大陆发行方案尚未由发行者决定。
- 若使用中国大陆服务器，ICP备案、接入商要求、域名和日志制度尚未确认。
