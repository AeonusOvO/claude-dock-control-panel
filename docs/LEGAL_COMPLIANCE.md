# ClaudeDock 中国大陆公开发行合规评估

评估日期：2026-08-03

这是一份产品风险清单和工程边界记录，不替代中国执业律师对发行主体、服务器部署、真实用户和运营方式
的正式法律意见。法律适用看功能与实际行为；“学生项目”“开源”“免费”“加速器”或免责声明都不是
当然豁免。

## 当前结论

1. **自动更新不要求自建服务器。** GitHub Releases 可直接承担更新；公开用户必须能匿名读取 Release
   的 `latest.yml`、安装包和 blockmap，不能把私有 GitHub Token 放进客户端。
2. **GitHub 与自建源可以并存。** 4.0.0 会对真实安装包各采样最多 256 KiB，自动选择更快来源。镜像
   元数据必须与 GitHub 的版本、文件名和 SHA-512 完全一致；GitHub 元数据不可验证时，客户端不信任
   镜像并回落到 GitHub feed。该策略优先供应链安全，意味着 GitHub 完全不可达时本版不会仅凭镜像
   自行更新。部署要求见 `UPDATE_MIRROR.md`。
3. **当前中国大陆服务器不能直接加入正式更新配置。** 客户端拒绝裸 IP/HTTP；还缺少更新域名、DNS、
   HTTPS 证书以及接入商对备案/公开下载的书面或控制台确认。持续向公众提供文件下载仍可能属于互联网
   信息服务场景，“只下载、不展示网页”不应被当作当然免备案结论。
4. **通用代理产品能力已从 4.0.0 发行代码删除。** 节点/订阅、Xray、隧道、出口、泄露体检和 Windows
   IPv6 修改入口均已删除。现在只配置用户已有代理的地址、端口和可选账号密码，类似常见软件的应用层
   代理设置，风险显著低于提供节点、线路或跨境出口。
5. **外部代理模式仍不是法律豁免。** ToDesk、QQ、微信存在代理/中继设置，不能证明其他软件可提供任意
   跨境信道。ClaudeDock 不审查代理后端是否具有许可或合同授权；公开说明必须要求用户合法使用，发行者
   仍应避免提供节点、订阅、共享账号、推荐线路、代购或以跨境访问为宣传卖点。
6. **当前 AI 客户端边界相对可控。** 用户自行选择服务商和密钥，维护者不集中接收提示词。如果以后提供
   自有 API、共享 Key、统一账号、云端对话存储或面向公众直接提供生成服务，应重新评估生成式 AI 服务、
   算法备案/安全评估、内容治理、生成内容标识、个人信息和跨境义务。

## 已完成的工程整改

- 删除通用代理 IPC、预加载 API、页面、运行服务、Xray 下载/启动代码、相关脚本与发行测试；旧版数据
  不读取、不启用，升级时也不擅自删除。
- 新外部代理只接受 HTTP/SOCKS5 主机、端口和可选凭据；密码通过 Windows DPAPI 加密。CLI 仅允许
  Claude Code 支持的 HTTP 代理，SOCKS5 只能用于 Electron session。
- 代理配置只影响用户勾选的 ClaudeDock CLI、应用网络或独立对话；不写 Windows Internet Settings、
  DNS、路由表、网卡或其他软件设置。
- 应用更新加入 GitHub/自建 HTTPS 双源自动择优、域名白名单、元数据大小上限、短超时和 GitHub
  元数据一致性校验；HTTP 镜像配置会被忽略。
- Claude Code npm 更新只对已确认的 npm 安装执行；用不超过 128 KiB 的样本比较 npm 官方源和
  npmmirror。原生安装沿用官方更新器，未安装使用官方 WinGet 包。
- 新安装默认开启增强隐私模式；设置中持续展示隐私与合规说明；独立对话模型回复显示“AI 生成”。
- 项目改用 Apache-2.0 开源许可，并记录第三方依赖许可维护义务。

## 外部代理的发行红线

公开版应继续保持以下边界：

- 不提供、销售、交换或推荐代理节点、订阅、账号、线路或公网出口；
- 不下载、捆绑或启动 VPN/代理内核，不建立 TUN/透明代理，不修改系统网络配置；
- 不宣传“翻墙”“突破地区限制”“访问被屏蔽服务”等用途；
- 不代用户选择境外出口，不承诺代理服务合法，不把用户勾选视为免除发行者责任；
- 企业内部若使用专线/VPN，应由单位确认电信服务、合同授权、用途范围、访问控制和审计要求。

如果以后要恢复节点/订阅/隧道能力，应视为新产品范围，先停止发布并取得针对实际方案的专项法律意见，
不能只靠改名、默认关闭或风险勾选恢复。

## 国内更新服务器审查

已审计的服务器资源足以运行静态 Nginx，但当前 4 Mbps 公网带宽更适合作为低并发兜底源。以约 132.5 MiB
安装包估算，理想满带宽单次下载约 4.6 分钟；300 GB/月理论上约 2,200 次完整下载，实际还要扣除
blockmap、失败重试、系统流量和协议开销。发布前需要：

- 一个专用更新域名及 DNS A/AAAA 规划；
- 接入商对 ICP 备案、公安联网备案和公开下载要求的确认；
- 可信 HTTPS 证书、443 入站规则、Nginx 静态目录和监控；
- GitHub Actions 使用独立部署密钥原子同步 Release 文件；私钥只存 Secrets，不进仓库或客户端；
- 稳定 Windows 代码签名证书。HTTPS 和 SHA-512 不能替代发布者签名。

- 《中华人民共和国计算机信息网络国际联网管理暂行规定》第六条等：国际联网应使用国家公用电信网
  提供的国际出入口信道。司法部法规库：
  <https://xzfg.moj.gov.cn/mobile/law/detail?LawID=1147>
- 工业和信息化部《关于清理规范互联网网络接入服务市场的通知》：未经批准不得自行建立或租用专线
  （含 VPN）等信道开展跨境经营活动；国际专线用途有明确边界：
  <https://www.miit.gov.cn/zwgk/zcwj/wjfb/tz/art/2017/art_a940645e940946e1a62cd6c90a4e994e.html>
- 工业和信息化部关于相关报道的回应：整治重点是未经主管部门批准、无国际通信业务经营资质而租用
  专线或 VPN 开展跨境电信业务经营活动：
  <https://www.miit.gov.cn/zwgk/zcjd/art/2020/art_6d942fea3c824343bdd1e01f2d6e12af.html>
- 《互联网信息服务管理办法》及非经营性互联网信息服务备案规则：经营性服务实行许可，非经营性服务
  实行备案：
  <https://www.miit.gov.cn/gyhxxhb/jgsj/cyzcyfgs/bmgz/xxtxl/art/2024/art_84a0cfa0ebd049bbbe751dca9a008e56.html>
- 《中华人民共和国个人信息保护法》：告知、最短保存、个人权利和向境外提供个人信息等规则：
  <https://www.miit.gov.cn/jgsj/zfs/fl/art/2022/art_515a4b20c12f430eab54bb4f56d89f56.html>
- 《生成式人工智能服务管理暂行办法》：面向中国境内公众提供生成式 AI 服务时适用：
  <https://www.cac.gov.cn/2023-07/13/c_1690898327029107.htm>
- 《人工智能生成合成内容标识办法》（2025-09-01 起施行）：对适用服务规定显式和隐式标识：
  <https://www.cac.gov.cn/2025-03/14/c_1743654684782215.htm>
- 《促进和规范数据跨境流动规定》：部分场景简化申报机制，但不免除处理合法性和安全保护义务：
  <https://www.cac.gov.cn/2024-03/22/c_1712776612187994.htm>

## 发布前仍未完成

- 发行主体的真实地址、持续有效邮箱/电话尚未提供；GitHub Issues 不应是唯一隐私联系渠道。
- GitHub 仓库和 Release 是否已公开需在发行前核验；客户端不能访问私有 Release。
- Windows 安装包尚未配置受信任代码签名证书，会出现未知发布者/SmartScreen 风险。
- 自建更新源仍缺域名、HTTPS 证书与备案/接入商确认，因此 `assets/runtime/update-sources.json` 仅启用
  GitHub。收到这些信息并部署通过后，才能加入国内镜像。
- 本评估需要由了解实际发行方式的中国执业律师复核，尤其是国内服务器、个人信息跨境和未来自有 API。
