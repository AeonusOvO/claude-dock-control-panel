上游接口
服务商给你的模型地址，例如带 /v1/chat/completions 的中转。
本地转换器 / 模型网关
把 OpenAI 格式翻译成 Claude Code 需要的 Anthropic 格式。
管理页 3458
用浏览器配置 Router，不是 Claude Code 应连接的 API。
模型接口 3456
Router 默认给 Claude Code 使用的地址，通常填到 API 基址。
两种密钥
上游密钥交给 Router 访问服务商；Router 访问密钥交给 ClaudeDock。两者可能不同。
